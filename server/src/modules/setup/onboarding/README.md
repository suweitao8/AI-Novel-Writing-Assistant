# 首书向导与创作环境状态

## 模块边界

- `CreationEnvironmentService` 只读取文本模型槽的当前配置，判断首书向导是否可以进入创作阶段；它不探测模型、不写设置，也不初始化任务路由。
- `FirstNovelOnboardingService` 只读取真实小说、章节和自动导演状态，生成第一本书里程碑投影。
- 模型配置的正式入口是 `/settings/models`；文本模型槽由模型设置页维护，运行时任务路由统一解析到该槽位。
- 前端不得自行勾选或伪造里程碑完成状态；首书进度只由服务端真实状态投影。

## 运行规则

- 文本模型是否可用由已保存配置、环境变量和注册表默认值按既有优先级计算；模型连通性检测由模型设置页显式执行。
- 文本任务的运行时路由统一使用文本槽当前模型，不需要额外写入一组初始化路由或维护另一份全局就绪状态。
- 首书环境未就绪时，投影的下一步是进入模型设置页；系统不会在全局布局中自动打开配置弹窗，也不会拦截 AI 操作按钮。
- 已有可读首章的项目直接视为首书向导毕业，不要求重新走引导。
- 本模块不管理小说生产，也不修改自动导演检查点；它只提供只读环境状态与首书引导投影。
