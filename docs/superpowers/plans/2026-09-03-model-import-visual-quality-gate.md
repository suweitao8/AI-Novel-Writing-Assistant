# Model Import Visual Quality Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prevent malformed or visually broken Cine57 models from entering the published model catalog by validating source alpha, final texture/material mappings, and real product detail-page previews before catalog publication.

**Architecture:** Add one import-audit module that probes source textures through `ffprobe`/`ffmpeg`, writes machine-readable evidence, and repairs alpha-bearing Base Color output to PNG with an opacity mapping. Extend the existing model-library quality gate so every published entry needs a real browser preview audit whose asset hash matches the current GLB and referenced textures; failed candidates stay outside the catalog and are listed in the existing reversible quarantine policy. Keep `modelLibrary.ts` generated by scripts and keep the product renderer as the preview authority.

**Tech Stack:** Node.js ESM scripts, FFmpeg/ffprobe, generated TypeScript catalog, PlayCanvas model detail page, built-in Browser Use (`iab`) for smoke/audit evidence, Node test runner, pnpm workflow hooks.
