# 角色模型纹理测试实施计划

> 目标：在模型库中增加“角色”分类，并复用当前动画预览使用的 UAL2 角色模型，提供一个只影响角色模型的程序化“男大学生测试纹理”外观，用于验证角色模型上色与后续图生图参考的可行性。

## 范围与约束

- 角色模型固定复用 "/anims/cine57/UAL2_UE_Anims.glb"，不复制或改动现有动画资产。
- 现有分镜阻挡、动画缩略图和动画预览继续使用蓝色模型，不改变其他页面的默认外观。
- 当前 UAL2 GLB 的 UV 坐标退化，不能把普通图片直接当作可靠的 UV 贴图；测试材质使用 PlayCanvas GLSL 位置投影，仅验证视觉上色链路。
- 本阶段不接入图片生成 API，不伪装成生产纹理。界面明确标识为测试纹理。
- 保持既有模型库、模型详情页和缩略图渲染入口，新增逻辑通过模型条目的预览外观配置启用。

## 实施步骤

### 1. 建立回归契约

- 增加模型库契约测试，验证“角色”分类和角色条目指向现有 UAL2 GLB。
- 验证角色条目声明专用预览外观，普通条目不受影响。
- 验证模型查看器和缩略图工作室都读取该预览外观配置。
- 先运行测试确认新增契约在实现前失败。

### 2. 添加角色条目与外观配置

- 在模型库分类中加入“角色”。
- 添加一个角色模型条目，复用 UAL2 文件、保持正确来源与尺寸信息。
- 为条目增加可选的预览外观标识，避免把角色测试逻辑硬编码到所有模型。

### 3. 实现角色外观控制器

- 新建模型库 3D 预览所属的角色外观模块。
- 生成固定尺寸、确定性的男大学生测试纹理：鞋、裤子、上衣、皮肤、头发等分区，并加入轻微织物变化。
- 创建 PlayCanvas 纹理和自定义 StandardMaterial，使用模型位置做圆柱投影以绕过退化 UV。
- 支持“男大学生测试纹理”和“蓝色模型”两种模式；复用蓝色模型的既有材质规则。
- 缓存材质和纹理，切换时复用，销毁时释放资源。

### 4. 接入模型查看器与缩略图

- 扩展模型查看器选项和实例 API，使角色条目默认使用测试纹理，并允许页面切换外观。
- 扩展缩略图工作室，使模型库角色卡片使用测试纹理。
- 保证普通模型仍走原有材质回填，动画缩略图链路不变。

### 5. 接入模型详情页交互

- 仅在角色测试条目显示“角色外观”切换按钮。
- 默认选中“男大学生测试纹理”，可切回“蓝色模型”对照。
- 使用现有 Button、Card、Inspector 分组和语义 token；按钮提供 selected/disabled/错误状态和可访问名称。
- 不增加 AI 生成按钮或图片生成接口，避免把一次性可行性测试误解为完整生图功能。

### 6. 文档与质量检查

- 更新用户可见发布说明和 README 最新更新，说明模型库角色测试预览能力。
- 若形成长期材质预览边界，补充开发 wiki；不记录临时改动清单。
- 运行角色契约测试、相关模型库测试、客户端类型检查、客户端构建和差异空白检查。
- 对照需求进行自验收：角色分类可见、角色卡片有颜色纹理、详情页可切换、其他角色/动画预览仍保持蓝色。

### 7. 浏览器验收与交付

- 使用 Codex 内置浏览器访问 "/models"，切换“角色”分类并验证角色卡片。
- 打开角色详情页，检查测试纹理渲染、蓝色对照切换、按钮状态和控制台错误。
- 访问 "/animations" 验证既有蓝色角色预览未被污染。
- 截取关键页面截图并记录浏览器控制台/网络结果。
- 通过签名提交、主分支集成、推送和最终工作树/远端状态核对完成交付。
