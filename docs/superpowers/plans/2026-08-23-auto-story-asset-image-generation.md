# 角色、场景、道具缺图自动生成实施计划

## 目标

在资产列表进入前端后，自动为角色、场景、道具的缺失默认状态图调用现有状态图片接口；对同一页面会话去重并限制并发；让资产卡片和侧栏即时显示生成中或失败。

## 实施步骤

### 1. 纯逻辑与测试

- 新增自动补图协调模块，定义资产类型、默认状态选择、缺图任务筛选和任务键。
- 实现可测试的有界并发调度器，默认并发数为 3；跳过后端已处于 `generating` 的状态，并限制同一会话对失败状态的自动尝试。
- 先添加 Node 测试覆盖任务筛选、默认状态、去重、失败重试边界和最大并发数。

### 2. React Query 自动协调器

- 新增无界面 React hook/component，读取三类资产列表并在数据刷新后扫描。
- 复用 `generateStoryAssetStateImage`，请求开始时乐观写入 `generating`，成功/失败时写回服务端资产或错误状态，并在批次完成后进行一次列表失效刷新。
- 在 `StorySettingsTabs` 与 `ComicDramaStudioPage` 挂载，覆盖设置页、漫剧工作室和缓存失效后的参考内容应用/快速创建场景。

### 3. 展示反馈

- 扩展 `StoryAssetStatePresentation`，携带图片状态和错误信息。
- 更新默认预览占位和 `StoryAssetCard`，对生成中的缺图使用语义高亮、加载图标和“生成中”文案，对失败状态显示“生成失败”；保留详情弹窗的手动生成/重试入口。
- 使用现有设计 token、Badge、图标和状态样式，不引入硬编码颜色或新的交互组件。

### 4. 验证与交付

- 运行新增自动补图测试、相关资产展示契约测试、客户端类型检查和服务端构建。
- 检查工作树只包含本需求的设计、计划和实现文件；内部实现跳过 release notes，并在交付说明中明确。
- 使用签名提交，合并验证分支到 `main`，显式推送 `origin/main`，再删除已合并的隔离工作树和本地分支。
