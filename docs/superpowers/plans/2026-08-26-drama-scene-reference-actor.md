# 场景 3D 参考角色校准 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让场景 3D 编辑器中的固定参考角色以 1.7 米高度位于世界原点，使用半透明空心选中环，并明确使用当前 HDRI atlas 参与角色光照。

**Architecture:** 场景页只传入场景专用的参考角色高度和初始位置；PlayCanvas viewer 的 `addActor` 增加可选位置参数，未传位置时保持分镜多角色原有排布。viewer 在角色材质上显式开启场景环境光照，在选中环材质上单独设置半透明和不写深度，HDRI 的显示与 lighting atlas 生命周期保持现有实现。

**Tech Stack:** React + TypeScript, PlayCanvas, Node `node:test` 契约测试, Vite browser smoke verification.

- [ ] **Step 2: Make the selected ring translucent and non-occluding**

Define the scene-independent opacity constant and configure the existing ring material:

```ts
const SELECTION_RING_OPACITY = 0.5;
const selectionColor = new pc.Color(0.02, 0.32, 0.1);
const selectionMaterial = createMaterial(selectionColor, SELECTION_RING_OPACITY);
selectionMaterial.depthWrite = false;
selectionMaterial.useLighting = false;
selectionMaterial.useSkybox = false;
selectionMaterial.emissive = selectionColor.clone();
selectionMaterial.emissiveIntensity = 0.35;
selectionMaterial.update();
```

Keep `createSelectionRingGeometryData()` unchanged so the ring remains hollow.

- [ ] **Step 3: Explicitly bind actor materials to scene lighting**

In `setEntityMaterial`, after setting the diffuse/metalness values, set:

```ts

material.useSkybox = true;
```

Then update the material as before. This makes each actor and recolored actor use the same `Scene.envAtlas` generated by `applyEnvironmentLighting`; the fallback ambient light remains unchanged when no HDRI is loaded.
