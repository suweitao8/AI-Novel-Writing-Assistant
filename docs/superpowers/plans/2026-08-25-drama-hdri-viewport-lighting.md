# 漫剧 3D 草图 HDRI 视口与角色基础打光 Implementation Plan

## Goal

消除普通场景图地面半球的圆形波纹，修正中键平移方向；将 HDRI 面板收敛为高度和直径两个参数，并依据场景图亮部给角色提供基础方向光。

## Architecture

保留 `layout3d.environment` 的兼容四字段结构，但运行时将 yaw 固定为 `0`、intensity 固定为 `1`。地面几何使用连续浅碗形，不在中心使用半径阈值。HDRI 光源估算放在无 PlayCanvas 依赖的纯模块中，viewer 负责读取纹理像素并更新方向光。

## Tasks

### Task 1: 锁定行为契约

- [ ] 更新客户端页面/viewer 契约测试：默认值、范围、隐藏控件、固定 yaw/intensity、连续地面和平移轴。
- [ ] 更新服务端契约测试：高度 `1–10`、直径 `10–50`，合法旧 yaw/亮度归一化为 `0/1`。
- [ ] 新增 HDRI 光源估算纯函数测试：亮部方向和空输入后备值。

### Task 2: 修正视口数学与交互

- [ ] 用连续地面曲面和连续投影 UV 替换硬阈值/截断逻辑。
- [ ] 用摄像机屏幕基向量处理中键平移。
- [ ] 修改客户端默认值、归一化和页面控件；同步服务端 limits 与 HTTP schema。

### Task 3: 接入图像主光估算

- [ ] 从 HDRI/普通场景图纹理缩略采样上方亮部，得到方向与颜色。
- [ ] 将估算结果应用到角色方向光；保留低强度冷色补光，并在像素读取失败时使用后备方向。

### Task 4: 文档、验证与交付

- [ ] 更新 release notes、README 最新更新和 3D 草图 wiki，记录固定参数与自动打光规则。
- [ ] 运行定向测试、typecheck、build，并检查固定端口 API/页面和控制台。
- [ ] 使用签名提交，从干净 `main` 集成、推送并清理本次 worktree。
