# 漫剧分镜统一写实媒介锁设计

## Background

当前漫剧分镜首帧的 `visualStyle` 主要表达时代与题材氛围，但首帧生成时又把每个镜头交给 `era_style_judge` 独立选择风格。可选清单同时包含 `live_action` 与 `animation`，解析器没有用 `styleFamily` 限制候选，因此同一项目可能在镜头之间从影视化写实跳到动画/卡通质感。实际项目数据中，第 1～3 镜和第 4～16 镜已出现不同时代风格提示词；第 8、9 镜虽然共享角色和场景参考图，生成质感仍可能漂移。

## Decision

保留“时代氛围可以随剧情变化”的能力，但把“渲染媒介”从时代判断中锁定：

1. 由项目显式风格（没有显式风格时使用 `realistic`）推导渲染媒介；内置 `post_apocalyptic`、`realistic` 等项目风格锁定为 `live_action`，`guoman_fantasy` 锁定为 `animation`。
2. 时代风格 AI 判定只能从与当前项目媒介相同的内置候选中选择。写实项目永远不能选动画候选；自定义时代风格只提供氛围，不改变项目媒介。
3. 资产图、状态图和分镜首帧都注入同一条媒介锁。当前默认写实媒介使用明确的“统一写实影视化”正向指令和卡通/动漫/插画/赛璐璐等负面约束；既有资产类别与时代氛围描述继续保留。
4. 现有已生成图片不在保存设置或部署代码时静默覆盖。批量首帧任务增加明确的 `force` 语义，允许用户在确认后按统一媒介重生成目标镜头；旧版本继续由现有 keyframe history 保留。

## Data flow

`DramaProject.visualStyle` → `resolveDramaArtStyleContext` 推导 `renderFamily` → 过滤时代判定候选 + 生成统一媒介提示词/负面提示词 → 资产/状态图/分镜首帧生成。

对当前“黑暗文明12”项目，`post_apocalyptic` 仍决定末世或现代环境氛围，但所有镜头的渲染媒介都固定为写实影视化；第 8、9 镜重生成后应保持相同的写实基线，仅允许景别、动作、光线和时代环境随分镜变化。

## Regeneration and UX

现有单镜“重新生成”继续可用；批量生成接口增加 `force` 选项，强制重新处理已完成首帧。漫剧分镜画面面板提供“按统一媒介重生成本集”入口，使用现有 `AiButton`/`Button`、状态反馈和确认对话框，生成中禁用重复提交，失败时保留重试入口。设置页只展示当前项目的媒介锁定状态，不新增让新手选择容易破坏连续性的自由风格组合。

## Error handling

- 无法识别项目风格或自定义风格没有媒介信息时，确定性回落到 `live_action`，不会回落到动画。
- AI 返回不在过滤清单中的风格时，保留兼容的项目时代风格；不阻塞分镜生成。
- `force` 批量任务只允许处理当前项目、当前集的镜头，并复用现有并发、失败记录和历史归档逻辑。
- 未确认的 3D 摆位草图仍按原合同阻止首帧生成。

## Verification

- 单元测试证明写实项目的时代候选不包含 `guoman_fantasy`，动画返回会回落到兼容风格，默认项目媒介为 `live_action`。
- 提示词契约测试证明资产图与分镜首帧均包含媒介锁，负面提示词包含禁止卡通/插画等约束。
- 批量任务测试证明 `force=false` 跳过已有首帧、`force=true` 重新处理已有首帧，并保留版本归档。
- 服务端类型检查、客户端类型检查和构建通过。
- 真实浏览器验证第 8、9 镜：重生成后两张图均使用写实媒介提示词，页面显示生成完成；通过 API/文件检查确认两张图实际更新且为横屏规格。

## Scope boundary

本次不改变角色、场景、道具的内容描述，不把现代与末世剧情强行合并成同一个时代，也不删除已有生成历史；只锁定渲染媒介并提供明确的重生成入口。
