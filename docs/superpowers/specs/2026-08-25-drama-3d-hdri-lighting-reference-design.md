# 漫剧 3D 场景 HDRI 光照与比例参照设计

## Background

当前 PlayCanvas 3D 查看器把场景状态图贴在半球上，但角色仍依赖独立的方向光和补光。这样角色的明暗方向与 HDRI 不完全一致，也会让场景编辑页的比例参照角色可以被拖离校准位置。用户需要用场景图本身作为环境光源，并在场景编辑时保持一个稳定的 1.8 米参照物。

## Decision

1. 删除 3D 查看器创建的方向光和补光。加载 HDRI 纹理后，通过 PlayCanvas `EnvLighting.generateLightingSource` 与 `EnvLighting.generateAtlas` 生成环境光照纹理，并写入 `app.scene.envAtlas`；角色的漫反射、反射和环境明暗统一来自 HDRI。
2. 没有 HDRI 时不伪造方向光，使用低强度中性 `scene.ambientLight` 作为可见性兜底；有 HDRI 时使用生成的环境光照图，环境半球仍用自发光材质负责显示原图细节。
3. 选中角色的地面环改为明确的绿色，并保留现有选中事件和缩放逻辑。
4. 查看器增加“角色位置移动”开关。分镜摆位页保持可移动；场景资产编辑页添加约 1.8 米参照角色后关闭该开关，因此左键仍可选中角色，但不能拖动或通过位置调整接口改变它，右键旋转、滚轮缩放和中键平移相机继续有效。
5. 代理模型按 Quaternius UAL2 GLB 的原始包围盒高度约 `1.8287m` 校准到 `1.8m`，以实际根节点缩放体现比例，而不是只在界面文案中标注“约 1.8m”。已保存的分镜角色布局继续读取自身缩放；新建的代理角色采用统一的 1.8 米基准。

## Boundaries

- 不修改场景 HDRI 的投射中心、半球直径、2:1/16:9 投影和已有布局持久化合同。
- 不把 HDRI 的派生光照结果写入 `layout3d` 或场景参数；它只随当前环境纹理在运行时生成。
- 不锁定分镜摆位页的角色操作；“不可移动”只作用于 `DramaScene3DPage` 的比例参照角色。
- 不新增 UI 颜色硬编码；绿色只作为 PlayCanvas 运行时选中标记的颜色值。

## Acceptance

- viewer 源码不再创建 `directional` 或 `omni` 灯光，并包含 `EnvLighting.generateLightingSource`、`EnvLighting.generateAtlas` 和 `scene.envAtlas` 的完整设置/清理链路。
- 有 HDRI 时角色仍可见且使用环境光照；无 HDRI 时使用中性环境光兜底，不重新启用人工主光/补光。
- 选中角色的环形标记为绿色。
- 场景 3D 编辑页显示参照角色固定提示；该页关闭角色位置移动后，参照角色不可被左键拖动，右键/中键/滚轮仍用于相机操作。
- 参照角色实际模型高度校准为 1.8 米，保存场景参数时不会把参照角色写入分镜角色数据。
