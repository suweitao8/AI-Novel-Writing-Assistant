# 动画预览工作台设计

## 背景

动画库当前点击卡片后只打开一个小型弹窗。弹窗使用简化布光，无法像模型库一样提供完整的 3D 工作台，也不能让用户精确选择动作中的某一帧作为卡片预览图。

同时，动画库页面使用 `UAL2_UE_Anims.glb`，而分镜 3D 草图仍然分别加载 UAL2 角色模型和 UAL1 动画资源。两条链路虽然依赖同名骨骼，但资源来源不同，后续继续扩展动作时容易出现“动画库能看、分镜没用上”的断链。

## 目标

1. 点击动画卡片进入独立的动画预览页面，而不是打开弹窗。
2. 预览页面提供完整的 PlayCanvas 3D 场景，复用模型库的 HDR 棚拍环境、可视穹顶、环境反射、阴影和轨道相机体验。
3. 预览页面能循环播放当前动作，也能暂停并通过时间轴精确定位到动作中的某一时刻/帧。
4. 用户可以把当前画布帧设为该动画的预览帧；动画卡片优先展示该截图，刷新页面后仍然保留。
5. 预览器和分镜 3D 草图使用同一个 UAL2 目标角色与动画资源，避免跨 UAL1/UAL2 资源装配造成的兼容性漂移。
6. 保留原有动画目录 id、`fileUrl`、`clipName` 和动作时长契约。

## 非目标

- 本阶段不增加服务端数据库字段；内置静态动画目录的关键帧保存到当前浏览器的 localStorage，避免为静态资源目录引入用户/项目数据模型。
- 本阶段不把分镜 3D 草图改造成完整动画剪辑器；分镜仍然保存一个用于构图的静态姿势，连续播放和逐帧选择属于动画预览工作台。
- 不修改 FBX 源资产或重定向算法；FBX 继续作为制作/UE 侧源格式，GLB 继续作为网页运行格式。

## 选定方案

采用“独立页面 + 共享运行时 + 单一 UAL2 GLB + 浏览器关键帧覆盖”的方案。

### 路由与页面

- 新增 `/animations/:animationId` 路由，卡片使用 `Link` 导航，浏览器后退可以回到动画库筛选状态。
- 页面结构参考 `/models/:modelId`：顶部返回、动作名称/分类/来源信息，主体为大尺寸 3D 画布，右侧为动作控制与元数据面板。
- 无效 `animationId` 显示明确的返回动画库入口；GLB 加载中显示加载态，加载失败保留重试/返回入口。

### 3D 运行时

- 抽取一个动画场景 viewer 模块，负责 PlayCanvas 应用、角色实例、HDR 棚拍布光、可视背景穹顶、轨道相机、资源释放和画布截图。
- 优先复用模型库已有 `studioLighting`、`studioBackdrop` 和包围盒/取景逻辑，不复制第二套 HDR 实现。
- 预览器直接加载 `/anims/cine57/UAL2_UE_Anims.glb`，从同一 `ContainerResource` 中实例化 UAL2 角色并收集动画轨道。
- 角色落地、居中和相机 fit 以当前选中动作的实时包围盒为准，避免坐姿/行走动作被裁切；相机拖拽、滚轮缩放与模型页保持一致。
- PlayCanvas 应用必须独占画布；React effect 清理时同步取消异步加载，避免 StrictMode 下残留 WebGL 应用。

### 时间轴与关键帧

- 运行时公开 `play`、`pause`、`setTime`、`getTime`、`getDuration`、`capturePng` 和销毁接口。
- 播放时由动作轨道驱动当前时间；暂停或拖动时间轴时，将动画层冻结在对应时间点，并向页面回报当前时间。
- 时间轴以 0 到动作实际 duration 映射，不用固定帧数猜测；同时显示秒数，便于精确定位。
- “设为预览帧”在画布已经完成该时间点渲染后截图，保存 `{ dataUrl, timeSeconds, updatedAt }`。
- 关键帧写入版本化 localStorage，例如 `animation-library:keyframes:v1`；卡片缩略图缓存读取关键帧覆盖，没有关键帧时才走默认缩略图生成器。
- 保存成功使用全局 `toast.success`，失败使用带原因的 `toast.error`；按钮在截图/写入期间禁用，防止重复写入。

### 分镜 3D 草图资源统一

- `blocking3dViewerApp` 改为加载同一个 UAL2 动画 GLB，使用该资源的角色实例与动作轨道。
- 现有 `blocking3dPose` 的语义姿势映射继续保留；动作库缺少某个语义姿势时仍按现有候选顺序报错或回退，不引入字符串匹配兜底。
- 分镜静态姿势依然通过动作轨道采样后暂停，保存到草图布局的仍是姿势语义和角色变换，而不是把动画时间线写入分镜数据。
- 只有在统一资源中的必需基础动作和目标 skin joints 校验通过后，才允许 viewer 完成初始化。

## 数据流

```text
动画卡片
  -> /animations/:id
  -> 读取目录条目 + keyframe override
  -> AnimationSceneViewer 加载 UAL2_UE_Anims.glb
  -> HDR 场景 + UAL2 角色 + 目标 clip
  -> 播放/暂停/时间轴 setTime
  -> capturePng + 保存关键帧
  -> 动画库卡片读取同一 keyframe override
```

## 交互与可访问性

- 卡片是标准链接，可用鼠标点击、Enter 和 Space 进入详情页。
- 播放、暂停、设为预览帧、返回和重置视角均为带 `aria-label` 的按钮；时间轴带可读标签和当前值。
- 画布保留键盘焦点样式；时间轴支持键盘方向键调整时间。
- 加载、空状态、错误、禁用、保存成功和保存失败均有可见状态；小屏幕下控制面板移动到画布下方，不让时间轴溢出。
- 遵循项目语义 token，不引入新的 UI 依赖或硬编码颜色。

## 测试与验收

### 代码测试

- 页面契约测试确认动画卡片导航到 `/animations/:animationId`，不再渲染预览 Dialog。
- viewer 单元测试确认时间映射、暂停定位、播放状态、截图接口和销毁清理。
- 关键帧存储测试覆盖写入、读取、损坏数据回退和版本键变化。
- GLB 内容测试确认 UAL2 角色和目录动作均能被同一资源加载；分镜需要的基础动作仍可解析。
- 客户端 typecheck 与相关 PlayCanvas/分镜测试通过。

### 浏览器验收

- 在 `/animations` 点击卡片进入独立页面，页面不是弹窗。
- 页面出现 HDR 棚拍背景、角色、地面阴影和轨道相机；GLB 请求成功且无控制台错误。
- 播放/暂停有效，拖动时间轴能看到对应动作帧，关键帧截图按钮成功反馈。
- 返回动画库后卡片显示刚刚保存的帧；刷新页面后仍显示该帧。
- 从真实分镜 3D 草图入口创建角色并切换站立/行走/坐姿，确认加载的是统一 UAL2 资源且无 T 姿、骨盆跳变或加载错误。

## 风险与回退

- 如果某些 UAL2 原生姿势动作不在合并 GLB 中，viewer 初始化错误应明确指出缺少片段；不能静默换回 UAL1，以免再次形成两套资源链路。
- 如果真实 HDR 资源加载失败，沿用模型库的程序化环境兜底，但页面必须仍可播放和选帧，并通过状态提示保留问题可见性。
- 如果 localStorage 被清空，卡片回退到动作默认代表帧，不影响动画播放。
