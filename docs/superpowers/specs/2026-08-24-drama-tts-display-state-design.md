# 漫剧分镜配音显示状态设计

## 背景

分镜配音行当前会把没有音频的分段显示成状态点和“未生成”文字。这个占位信息不能帮助用户试听，也让没有音频时的区域看起来像一个空播放器。

## 目标

让配音区只展示用户可以直接操作的内容：有真实可播放音频时展示播放器，没有真实可播放音频时只展示生成入口。

## 交互规则

- 以 `status === "ready" && audioUrl` 作为“可播放音频”的唯一判断。
- 当前分镜没有任何可播放音频时，隐藏音频状态点、进度条和“未生成/需重配”等占位文字，只在音频区右侧显示「生成配音」按钮。
- 当前分镜只有部分分段可播放时，只展示可播放分段的播放器；不可播放分段不渲染占位行。按钮仍显示「生成配音」，用于补齐缺失或过期分段。
- 当前分镜所有分段都可播放时，展示全部播放器，按钮显示「重新生成」。
- 生成进行中保留按钮的 loading 文案和禁用态；已有真实音频继续可试听，尚未产生真实音频的分段不显示播放器。
- 旁白/对白正文展示逻辑不变；真实音频的当前秒数与总秒数仍只由播放器展示。

## 实现边界

- 只修改 `ShotVoiceListPanel.tsx` 的分镜行渲染和对应客户端契约测试。
- 继续复用现有 `AudioSegmentPlayer`、`AiButton`、语义颜色 token 和现有配音生成回调。
- 不修改配音生成接口、数据库字段、服务端状态模型或音频时长计算。

## 验收标准

- 未生成、生成中、失败、过期且没有可播放地址的分镜不会出现“未生成”或空进度条。
- 无可播放音频时，生成按钮仍可点击并位于配音区右侧。
- 部分完成时只显示已有播放器，并保留生成入口。
- 全部完成时显示全部播放器和“重新生成”。
- 现有配音按钮 loading、播放器拖动进度和单镜生成回调不回归。
