# 漫剧场景全景地面分界设计

## Background

场景状态图使用 2:1 等距柱状全景作为 HDRI 环境。当前生成提示词虽然要求地平线位于图片中线、下半区以地面为主，但图片模型仍可能把床、桌子、椅子或其它高大物体画到下半区。投影端又把图片中线 `v=0.5` 固定映射为 3D 地面分界，用户无法修正已有全景图，因此跨越分界的家具会在半球地面上产生明显割裂和拉伸。

## Decision

同时修正生成侧和投影侧：

1. 所有场景全景生成入口都采用严格的上下分区提示词：图片上半区承载天空/天花、墙面、远景和完整固定物体；图片下半区只承载连续地面/地板/地形及少量低矮自然细节。固定物体必须完整位于中线以上，并在中线附近留出干净安全边距；不得出现家具腿、树干、建筑、岩石或物体残片向下半区延伸。
2. 场景资产 3D 环境增加 `panoramaHorizonV`，表示图片纵向取哪一条线作为 3D 地面起始线。默认 `0.5`（50%），允许 `0.40–0.65`。数值越高，越多图片内容留在上半球，图片下方作为地面的区域越纯。
3. 场景 3D 编辑器在现有 HDRI 控制区增加“全景地面分界”滑块；参数与投射中心高度、半球直径相同，退出编辑器时统一保存到场景资产。分镜 3D 草图读取场景参数，复用同一分界，不单独建立一套值。
4. 等距柱状投影的纵向公式改为 `v = panoramaHorizonV - asin(direction.y) / PI`，水平投影、半球几何、HDRI 环境光照和角色材质保持不变。旧环境 JSON、旧分镜布局和缺失字段统一回落到 `0.5`，不做数据库迁移。

## Data flow

```text
场景状态/旧场景全景生成
  └─ strict panorama split prompt + negative constraints
      └─ 2:1 equirectangular image
          └─ scene3dEnvironment.panoramaHorizonV (default 0.5)
              ├─ 场景 3D 编辑器滑块 → 预览 → 退出保存
              └─ 分镜 3D 草图读取同一值 → 同一投影
```

`panoramaHorizonV` 只影响环境贴图的纵向采样，不影响 `projectionCenterHeight`、`domeRadius`、HDRI 光照贴图生成、角色高度或布局坐标。这样调整地面分界不会改变场景尺度或角色受光。

## Compatibility and validation

- 服务端场景环境 schema、归一化、序列化和分镜布局环境归一化都兼容缺失字段。
- 客户端投影 CPU 数学测试覆盖默认中线、向上/向下分界偏移、两极和经度连续性。
- 服务端提示词测试覆盖严格上下分区、物体安全边距和负向约束；旧版场景生成入口与状态图入口均覆盖。
- 浏览器验证真实场景 3D 编辑器显示 50% 默认值，拖动后预览中的地面分界即时变化，退出后重新进入仍保持；分镜 3D 草图验证复用同一参数。
