# 漫剧 3D 角色选中外描边设计

## 背景

分镜 3D 草图和场景 3D 编辑器目前用绿色 AABB 线框表示选中的角色。线框只反映模型包围盒，和人物真实轮廓不一致，尤其在角色姿势、怪物体型或参考角色较复杂时会遮住过多画面。

## 决策

- 选中角色时改用 PlayCanvas 的屏幕空间轮廓渲染器，描边沿角色真实可见轮廓生成，不再绘制 AABB 盒子的 12 条边。
- 轮廓渲染使用独立的临时渲染层。角色模型仍只在正常世界层渲染，避免把轮廓采样层意外画进主场景两次。
- 角色和参考角色统一支持外描边；「世界」和场景空间标记继续使用各自的现有反馈，不参与角色轮廓渲染。
- 选中状态改变时只把当前角色加入轮廓渲染器；取消角色选择、选中空间标记或销毁查看器时移除轮廓资源。
- 轮廓是编辑器反馈，不应污染保存的 3D 草图 PNG。捕获前暂时移除当前轮廓，捕获完成后恢复编辑器状态。

## 运行时约束

- 轮廓渲染器每帧同步当前相机的变换、投影和渲染目标尺寸，并在主相机的 Immediate 不透明层合成，以保证轮廓位于角色和 HDRI 场景之上但仍处于 UI 之前。
- 角色材质必须保持 `StandardMaterial`，因为 PlayCanvas 的轮廓渲染器会为标准材质注入轮廓 pass 的 shader 参数。
- 轮廓渲染层只属于查看器实例；销毁时先从轮廓渲染器移除角色，再销毁渲染器并从场景层组合中移除临时层。

## 验收标准

1. 角色、怪物和参考角色选中后显示贴合模型真实轮廓的绿色外描边，不显示矩形包围盒。
2. 取消选择或选择「世界」/空间标记后，角色外描边消失，原有圆环和标记反馈保持不变。
3. 角色移动、旋转、切换姿势、调整比例和切换镜头视角后，描边仍与模型轮廓重合。
4. 导出的 1280×720 3D 草图 PNG 不包含绿色选中描边。
5. 相关契约测试和客户端构建通过，并在真实 3D 编辑页面确认视觉结果。
