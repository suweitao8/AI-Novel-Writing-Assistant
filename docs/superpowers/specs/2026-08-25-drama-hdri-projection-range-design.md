# 漫剧 3D 草图 HDRI 参数范围设计

## 背景

当前投射中心高度和半球尺寸的范围偏窄，无法覆盖 Unreal HDRIBackdrop 中更自由的构图调节。投影算法本身已经使用世界中心 `(0, height, 0)`，本次只扩展可调范围和用户可见语义，不恢复贴图 repeat。

## 决策

1. `projectionCenterHeight` 的有效范围调整为 `0.6–10`，默认值保持 `1`。投射中心 X/Z 继续固定为世界原点，只有 Y 高度可调；普通场景图地面仍按投射方向单次采样。
2. 现有 `domeRadius` 数据字段继续保留以兼容已保存的 `layout3d`，但它对应当前半径 0.5 的基础网格缩放，因此用户可见的半球直径调整为 `20–100`，默认值保持 `48`。界面标签改为“半球直径”，步进为 1。
3. 客户端 viewer、页面 range、服务端归一化边界和 HTTP schema 必须使用同一组范围。旧快照字段名和 schemaVersion 不变；超出新范围的数据仍拒绝或归一化到边界。
4. `domeRadius` 改变时继续重建普通场景图地面 UV；投射中心高度改变时同样重建 UV。天空/地面实体使用统一半球尺度，位置固定在世界原点。

## 验证

- 契约测试覆盖页面的 `0.6–10`、`20–100` 控件范围和服务端边界拒绝。
- 客户端 typecheck、服务端 typecheck、定向测试和完整构建通过。
- 固定端口页面能显示新范围，调整控件后没有控制台错误；保存/加载仍保留四字段环境数据。
