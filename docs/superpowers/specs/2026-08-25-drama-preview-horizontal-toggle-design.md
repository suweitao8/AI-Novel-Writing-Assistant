# 分镜预览水平切换设计

## 目标

让分镜卡片中的 `3D图 / AI图` 明确呈现为一组水平切换：左侧固定 `3D图`，右侧固定 `AI图`；切换区域下方继续放置本镜的三个操作按钮。

## 当前问题

预览图右侧控制栏目前把两个预览 tab 纵向堆叠，用户不容易一眼判断它们是互斥的预览切换，而且占用了操作栏的垂直空间。

## 设计

- 保留左侧 16:9 预览区、右侧控制栏以及现有三个操作按钮的整体结构。
- 右侧控制栏顶部使用 `role="tablist"`，设置 `aria-orientation="horizontal"`，采用两列布局：左列 `3D图`，右列 `AI图`。
- 选中态、禁用态和无 AI 图时强制回退到 3D 草图的规则保持不变：没有可用 AI 图时 `3D图` 选中，`AI图` 禁用；AI 图准备好后可以点击切换。
- 水平 tab 使用左右方向键切换，保留可见 focus ring、`aria-selected`、`aria-controls` 和活动 tab 的 `tabIndex` 管理。
- 水平切换下面按固定顺序放置三个按钮：`编辑3D`、`AI摆位`、`生成AI图`/`重新生图`。按钮的 loading、禁用和 AI 引导行为保持现有实现。
- 只调整前端布局和 tab 键盘方向，不新增接口、不改变图片生成、AI 摆位、草图保存或缓存逻辑。

## 验收标准

1. 每个分镜卡片都能看到水平排列的 `3D图` 和 `AI图`，顺序始终为左 3D、右 AI。
2. 切换区域位于三个操作按钮上方，三个按钮顺序和原有状态行为不变。
3. tab 仍符合 ARIA tablist 结构，鼠标点击和左右方向键都能切换；上下方向键不再被当作水平 tab 操作。
4. 3D 草图兜底、AI 图禁用、AI 图加载失败回退、生成中禁用等状态不回归。

## 验证

- 更新 `client/tests/shotVoiceBlockingSketchEntry.test.js` 覆盖水平方向、两列布局和按钮顺序。
- 运行分镜预览相关 Node 测试、客户端 typecheck 和 production build。
- 使用当前浏览器打开分镜 tab，确认真实卡片呈现左 3D/右 AI 的水平切换，并确认三个按钮位于其下方。
