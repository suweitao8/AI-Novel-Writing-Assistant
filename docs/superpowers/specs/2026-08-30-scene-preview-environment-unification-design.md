# 场景预览 HDR 半圆环境统一设计

## 背景

漫剧场景资产的 3D 预览已经使用有限半圆穹顶：HDR 全景图先重投影成 cubemap，再由固定在世界原点的投影材质从投射中心向穹顶/地面采样；环境光 atlas 只负责照明，编辑器网格是独立的地面辅助层。模型预览目前只复用了可见穹顶的一部分逻辑，环境光和可见背景分别加载，同一 HDR 可能被重复加载；动画实时预览仍使用独立平面地面，动画缩略图又维护了另一套平面和网格。因此相机旋转时不同预览入口的背景表现、投射中心和半径语义不一致。

## 目标

1. 模型实时预览、动画实时预览、模型缩略图和动画缩略图都使用漫剧场景资产同源的有限半圆 HDR 环境。
2. HDR 可见背景固定在世界原点，不随相机轨道旋转；相机只改变观察角度。
3. 所有入口使用同一套环境运行时和同一套设置语义：半球直径是完整直径，不是半径；默认投射中心高度为 2m，默认半球直径为 15m，默认全景地平线为 50%。
4. 所有入口的地面网格由同一个环境网格实现生成，网格范围跟随半球真实半径，不再使用动画预览的固定 3m 平面。
5. 模型已有的 HDR 预设选择和 5–30m 直径调节继续可用；直径变化只重建环境几何和投影参数，不重复加载 HDR 资源。

## 非目标

- 不修改漫剧场景状态的数据结构、HDR 资源生成方式或视频合成流程。
- 不把模型/动画编辑器改造成完整的漫剧场景编辑器；模型变换 gizmo、动画播放控制和相机交互保持现状。
- 不增加另一套环境参数存储；模型本机直径偏好只保留为现有 UI 的持久化入口，并迁移到统一默认值。

## 方案

### 统一环境运行时

在模型预览环境模块中保留一个面向模型/动画预览的薄适配层，但内部直接装配漫剧 `createBlocking3dEnvironmentRuntime`。适配层负责：

- 按预设顺序加载 HDR 资源，并在失败时沿用现有兼容资源兜底；
- 对同一张已加载的纹理同时生成可见投影 cubemap 和环境光 atlas；
- 始终移除相机的 SKYBOX 层，使 env atlas 不会被当作跟随相机的无限天空球；
- 暴露当前规范化后的环境设置、`applySettings`、`rebuild` 和 `destroy`；
- 用同一个 finite dome、shadow catcher 和投影材质完成背景及地面。

模型环境切换只替换 HDR 资源；模型直径调节复用当前运行时的几何重建能力，不重新下载或生成灯光资源。动画实时预览和两种缩略图使用默认室内 HDR 与相同的 15m/2m 设置。

### 统一设置

环境设置沿用漫剧 3D 合同：

```ts
{
  projectionCenterHeight: 2,
  projectionCenterHeightRatio: 2 / 15,
  domeRadius: 15, // 对用户表示完整直径；内部基础网格仍按 0.5 缩放
  panoramaHorizonV: 0.5,
  yawDeg: 0,
  intensity: 1,
}
```

所有预设使用相同的默认直径与投射中心；保存过的模型直径仍按 5–30m 限制恢复。设置变化后，网格范围使用同一份半球真实半径和地面可用半径计算，避免 3D 背景与地面辅助线脱节。

### 统一地面网格

从漫剧 3D 查看器抽出环境网格的纯构建/绘制责任到 `blocking3d` 环境模块。网格线颜色、主网格间距、次网格间距和 Y 偏移保持漫剧现有样式；边界范围由统一环境设置计算。漫剧查看器、模型查看器、动画预览和缩略图只调用这一实现，不再各自写 `-3..3` 或 `-10..10` 的网格循环。

实时编辑器显示网格，缩略图沿用同样的环境几何和网格范围后抓取画面，确保模型卡片和动画卡片的地面表现一致。

## 数据流与生命周期

```text
HDR URL -> loadAsset (一次)
             ├─ configureEnvironmentTexture
             ├─ createVisibleHdriCubemap -> finite projected dome
             └─ EnvLighting.generateAtlas -> scene.envAtlas (仅照明)

normalized settings -> backdrop + shadow catcher + projection uniforms
                    -> shared ground grid overlay
camera orbit --------> camera only; dome/entity remains at world origin
```

加载失败时保留现有程序化三灯布光，并让调用方收到无可见 HDR 背景的句柄状态；销毁时必须释放 cubemap、atlas、原始 asset、穹顶和 shadow catcher，且不能残留 WebGL 应用或事件监听器。

## 验证

- 单元/契约测试证明统一默认值、直径语义、唯一运行时入口、固定原点和网格范围契约。
- 动画预览测试证明不再创建旧的固定平面地面，且实时预览装配统一 HDR 运行时。
- 模型与动画缩略图测试证明使用相同的环境装配入口和默认设置。
- 客户端 typecheck 与相关测试通过。
- 在隔离浏览器标签中打开模型库、动画库及可用的 3D 预览路径，检查 HDR 半圆背景、相机旋转时背景固定、地面网格一致，并确认无新增 console error；若本地数据库没有可用资产，则记录具体受限路径，不把基础页面响应误当作 3D 验收。
