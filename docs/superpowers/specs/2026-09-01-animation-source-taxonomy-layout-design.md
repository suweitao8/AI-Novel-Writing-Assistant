# 动画来源分类与筛选栏布局设计

## 背景

动画库当前已经在数据层区分 `unreal`（虚幻/Cine57 导入动画）与 `legacy`（网站内置 UAL2 动画），但入口页只把“分镜可用 / 兼容动画 / 全部”作为用途页签展示，用户不能直接按资源来源浏览。当前筛选栏把用途、动作分类和搜索压在同一行，在可用宽度不足时不利于继续扩展分类。

模型库已经采用“左侧分类、右侧搜索”的紧凑筛选栏模式。本次动画库沿用该模式，但保留用途筛选，因为用途和来源表达的是两种不同事实：来源回答“动画来自哪里”，用途回答“当前能否直接用于分镜”。

## 目标

1. 在动画入口提供统一的来源分类：`全部`、`虚幻动画`、`网站内置动画`。
2. 来源分类按 `AnimationLibraryEntry.source` 筛选，不把虚幻资产的内部套装或动作组暴露为并列来源分类。
3. 保留现有用途筛选与动作分类筛选，并使来源、用途、动作分类可以组合使用。
4. 默认用途为 `全部`，让两个来源分类在首次进入页面时都能被看到；用户仍可切换到“分镜可用”或“兼容动画”进行用途约束。
5. 搜索框和“搜索”按钮在桌面端占据右侧位置；来源分类在剩余空间中自然换行，不挤压搜索控件。
6. 窄屏下筛选控件按完整行顺序堆叠，所有按钮、输入框和下拉仍可操作，不出现横向溢出或裁切。

## 设计

### 数据与筛选合同

- 新增来源筛选类型 `AnimationLibrarySourceFilterId = AnimationLibrarySource | "all"`。
- 新增来源选项配置，稳定顺序为：
  - `all`：全部
  - `unreal`：虚幻动画
  - `legacy`：网站内置动画
- `AnimationLibraryFilters` 增加 `source` 字段。来源条件与既有 `scope`、`actionType`、搜索条件使用交集，而不是互相覆盖。
- `sourceLabel` 与 `groupLabel` 继续保留给卡片与详情上下文；来源页签不复用内部 `ANIMATION_LIBRARY_GROUPS`，避免把虚幻内部组误解成来源。
- 既有 `storyboard`、`compatibility`、`all` 用途筛选语义不变，仅将页面初始值从 `storyboard` 调整为 `all`，并将重置动作恢复到 `all`。

### 筛选栏排布

筛选区域保持一个卡片容器，内部按两行组织：

第一行：

- 左侧为“来源”标签和来源页签。
- 来源页签容器允许换行，且受剩余空间约束。
- 右侧为搜索表单，桌面端 `margin-left: auto`，输入框与“搜索”按钮保持同排。
- 搜索仍然只在点击“搜索”或按回车时提交；不新增自动提交行为。

第二行：

- 保留“用途”页签。
- 保留“动作分类”下拉。
- 该行在需要时继续允许内部换行，但不能把第一行的搜索控件挤出可视区域。

布局使用现有 Tailwind 语义 token、`Tabs`、`SelectControl`、`Input` 和 `Button`，不新增组件库或硬编码颜色。来源页签使用与模型库一致的紧凑高度、圆角和激活态。

### 交互与可访问性

- 来源、用途页签使用现有 Tabs 交互：鼠标点击和键盘焦点均可切换，激活项暴露 `aria-selected`。
- 来源和用途切换都将动作分类恢复为“全部”，并回到第 1 页，防止旧动作分类与新范围无交集时出现空结果。
- 搜索表单保留可见的“搜索”按钮、输入框标签和 Enter 提交。
- 来源页签显示当前筛选范围内的条目数量；数量不显示在搜索框旁。
- 有任意非默认来源、用途、动作分类或已提交搜索时，保留“清除筛选”入口。
- 无结果时保留现有空状态，不因新增来源筛选而出现空白页面。

## 不在本次范围内

- 不改变 GLB 文件、骨架、动作片段、预览渲染或导出格式。
- 不删除 `ANIMATION_LIBRARY_GROUPS`、套装和细分类数据；这些数据仍由内部配置和卡片详情使用。
- 不改动模型库的分类逻辑或模型卡片。
- 不引入 URL 查询参数或持久化筛选状态。

## 验收标准

1. 代码级测试确认来源选项只包含“全部 / 虚幻动画 / 网站内置动画”，来源筛选能分别返回对应 `source` 的条目，并能与用途和搜索取交集。
2. 页面级测试确认来源筛选使用独立标识，默认用途为 `all`，来源和用途切换会重置动作分类与页码，搜索仍可按钮或回车提交。
3. 客户端类型检查和聚焦测试通过。
4. 内置浏览器在 `/animations` 验证：首次看到两类来源入口；点击两类来源后卡片范围正确变化；搜索框位于桌面端右侧；窄屏时控件换行且无横向溢出；控制台无错误。
