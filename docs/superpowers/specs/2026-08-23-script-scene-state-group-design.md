# 脚本场景与角色状态连续分组设计

## 背景

脚本页把场景行和场景下的角色状态面板渲染成两个独立卡片：两者分别有自己的圆角、背景和间距，用户难以判断角色状态属于哪个场景。

## 决策

为每个场景建立一个视觉分组容器，统一包住场景行与角色状态面板：

- 分组沿用场景行现有的 emerald 语义色，外层统一背景、边框和圆角。
- 场景行保留顶部操作内容，但不再单独绘制卡片圆角和背景。
- 角色状态面板作为分组的下半段，使用透明背景和顶部细分隔线，不再有独立圆角或外部间距。
- 一个场景下的多个角色状态仍在同一个面板内排列，桌面端三列、窄屏自动降为单列。
- 不改变 `ScriptItem`、脚本序列化、状态切换或自动保存逻辑；本次只调整脚本页的视觉结构。

## 验收标准

1. 场景行和角色状态行共用一个连续的视觉容器，颜色一致且中间没有卡片间隙。
2. 同一场景的多个角色状态仍作为一个整体显示，不与下一个场景混淆。
3. 没有角色状态时，场景行仍保持原有可用性和完整圆角。
4. 场景状态下拉、角色状态下拉、行操作和自动保存行为不变。
5. 客户端契约测试、类型检查和生产构建通过。
