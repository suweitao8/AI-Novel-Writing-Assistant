# 漫剧 3D 对象列表命名与高度布局设计

## Background

当前场景 3D 编辑器已经把场景、空间标记和比例参照放进同一个对象列表，但 HDR 环境对象显示为“场景对象”，比例人物显示为“比例参照”，对象语义不够直观；同时对象列表的固定行高偏大，压缩了下方属性编辑区。

## Goals

- HDR 环境对象在对象列表和选中属性中统一显示为「世界」。
- 用于尺度校准的人物在对象列表和属性中统一显示为「参考角色」。
- 当前状态已识别的全部空间标记继续作为独立对象行直接显示，并保持可选中、可聚焦和属性查看。
- 右侧对象列表固定约占面板高度的三分之一，属性面板使用其余空间；属性内容过多时只在属性卡内部滚动。
- 压缩对象卡和属性卡的顶部间距，保留当前主题 token、Card/Button 和现有选择状态。

## Design

### Object list semantics

`Drama3DObjectPanel` 仍然只负责展示对象图标、名称和选择状态。场景编辑页的静态环境对象使用 `label: "世界"`，比例人物使用 `label: "参考角色"`；属性面板的类型徽标、字段名称和聚焦按钮同步使用相同语义。空间标记直接使用模型返回并经过当前环境校准后的 `marker.label`，不新增分组折叠或分页，以便用户一次看到所有识别结果。

分镜 3D 草图页继续展示场景、角色、空间标记三类对象；场景编辑页展示世界、空间标记和参考角色。列表顺序保持稳定：世界/场景在前，空间标记和镜头角色居中，参考角色作为场景页的比例基准项置后。

### Right panel layout

`Drama3DEditorShell` 的右侧网格使用两个明确的 track：对象区 `minmax(0, 33.333%)`，属性区 `minmax(0, 1fr)`，两者之间使用紧凑间距。对象卡和属性卡都填满各自 track；对象行和属性内容分别在自身区域内处理溢出，属性区不会被对象数量或字段数量撑高。

对象卡标题使用紧凑的上下内边距，属性卡标题同样减少无效留白，使属性编辑入口在对象列表下方更靠上。响应式窄屏仍保持对象区在上、属性区在下，并允许外层工作台滚动。

### Data and interaction

不修改数据库字段、API 响应或 3D viewer。名称是现有对象项的展示文案；空间标记的选择、聚焦和尺寸/位置属性继续复用现有回调。属性面板的 loading、disabled、empty 和错误状态保持现有实现。

## Verification

- 契约测试确认两个页面分别展示「世界」/「参考角色」以及全部空间标记，旧的对象展示文案不再作为具体对象名称出现。
- 契约测试确认 shell 使用三分之一对象区和剩余属性区的 grid track，并保留卡片内部滚动。
- 运行客户端定向契约测试、客户端类型检查和生产构建。
- 用当前浏览器打开场景 3D 编辑器，确认对象列表名称、标记行、列表/属性区高度和属性编辑可见性。
