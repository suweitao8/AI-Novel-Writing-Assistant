# 模型与动画预览阴影可读性设计

## 背景

模型卡片的离屏缩略图与模型详情页使用同一套 HDRI 预览环境，但两条入口的阴影开关不一致：详情页实例化模型时允许投射阴影，缩略图却显式关闭了 `castShadows`。动画缩略图还关闭了地面 shadow catcher。因此用户在卡片上看不到投影阴影，点进详情页才看到阴影；即使详情页能看到，当前模型 profile 的 `shadowIntensity = 0.30` 也会让阴影过淡。

## 目标

1. 模型和动画卡片缩略图都显示与详情页一致的模型投射阴影。
2. 模型落地阴影保持柔和，但在缩略图尺寸下仍有明确的灰阶和接触关系。
3. 通过调整预览主光的水平来向，让阴影投向模型可见的一侧；不改变 HDRI 可见背景的方向，也不把方向光翻到模型下方。
4. 卡片缩略图只保留模型/角色、HDRI 背景和真实投影阴影，不绘制编辑器网格辅助线。
5. 旧的无阴影或带网格缩略图必须自动失效并重新生成，不依赖用户手动清理浏览器缓存。
6. 默认 profile 的漫剧、分镜和纯 HDRI 预览行为保持不变；详情编辑器仍可保留网格辅助线。

## 方案

### 1. 统一阴影参与者

- 模型缩略图的 `instantiateRenderEntity` 使用 `castShadows: true`。
- 动画缩略图的角色实例使用 `castShadows: true`。
- 动画完整预览与动画缩略图都使用 `model-preview` profile，避免同一动作在卡片和详情页出现两套光影。
- 动画缩略图移除关闭 shadow catcher 的选项，沿用共享运行时默认的接收器。
- 可见 HDRI 穹顶继续 `castShadows: false, receiveShadows: true`；它只负责背景和接收地面投影，不能挡住主光。

### 2. 只旋转模型预览主光

在 `model-preview` lighting profile 中增加主光水平偏转参数 `keyLightAzimuthOffsetDegrees = 180`。环境运行时把 HDRI 估算出的方向保持在原有高度，只绕世界 Y 轴水平旋转 180°后应用到方向光。这样：

- HDRI 可见穹顶和 `envAtlas` 的背景/反射方向保持不变；
- 主光仍然从上方照射，不会因整体取反而从地面下方照射；
- 投影阴影朝相反的水平侧展开，缩略图中更容易观察到。

默认 profile 的偏转为 0°，避免影响分镜、场景和其他共享预览。

### 3. 提升阴影可读性并统一出图外观

- 模型 profile 的 `shadowIntensity` 使用 0.62，与现有模型预览契约中定义的可读阴影值一致；环境补光和 PCF5 保持不变，避免暗部重新压黑。
- 模型、动画离屏相机不再强制使用 ACES，采用与详情页一致的 PlayCanvas 默认 Linear 色调映射，减少缩略图与详情页的对比度差异。
- 模型和动画卡片缩略图的离屏出图只调用 `app.render()`，不调用编辑器网格绘制函数；共享 shadow catcher、HDRI 和模型投影阴影继续参与渲染。
- 模型缩略图缓存键升至 `model-library:thumbnails:v26`，动画缩略图缓存键升至 `animation-library:thumbnails:v12`，使旧的带网格图自动失效。

## 验证

- 单元测试覆盖水平旋转保持高度、长度和 180°结果；profile 锁定偏转与阴影强度。
- 契约测试覆盖模型/动画缩略图的 `castShadows`、shadow catcher、Linear 色调映射、无编辑器网格绘制和缓存版本。
- 运行客户端类型检查与构建。
- 使用内置浏览器打开 `/models` 和一个模型详情页，确认卡片缩略图重新生成、投影阴影可见、详情页和卡片光影方向一致，控制台无错误；再打开 `/animations` 确认动画卡片正常出图。

## 非目标

- 不旋转 HDRI 可见背景或修改素材文件本身。
- 不修改默认共享光照 profile，不调整场景/分镜的阴影策略。
- 不清空数据库或删除用户资产；仅通过版本化 localStorage 缓存自然淘汰旧缩略图。
