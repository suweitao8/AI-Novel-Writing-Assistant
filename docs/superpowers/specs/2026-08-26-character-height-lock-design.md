# 3D 草图锁定角色大小与身高展示设计

## Background

角色的近似身高已经参与 3D 草图的代理模型比例，但草图页面仍保留“缩小角色 / 放大角色”按钮。手工缩放会绕过角色级身高基准，让同一角色在不同镜头中再次产生大小漂移。角色身高应当由角色设定推断并在角色信息中展示，3D 草图只负责位置、旋转、姿势和相机，不提供改变角色整体大小的操作。

## Decision

移除 3D 草图页面的手动缩放入口和 viewer 的 `scaleSelected` 公共操作。角色创建时继续使用 `heightMeters` 换算代理模型的初始比例；自动构图和历史布局的内部 `scale` 字段继续保留，用于兼容已有快照和系统生成的布局，但用户不能在 3D 草图中直接修改它。

在 3D 草图“本镜角色”列表中显示角色的近似身高，并在“空间摆放”信息中显示当前选中角色的身高基准，不显示可编辑的缩放数值。角色资产卡片和编辑区域继续只读显示身高；不新增手工身高输入，也不改变身高推断、缓存和 fallback 规则。

## Interaction and compatibility

- 角色仍可拖动/按钮移动、旋转、切换静态姿势、改变代理颜色；这些操作不改变高度比例。
- 相机滚轮缩放仍然保留，它改变视角距离而不是角色模型大小。
- 旧布局中的 `scale` 字段继续可读写，保证历史草图可打开；打开后不再有 UI 入口改变该值。
- 身高字段缺失时继续使用既有兼容高度，角色列表显示 `—` 或兼容高度由上下文决定，不阻塞草图编辑。
