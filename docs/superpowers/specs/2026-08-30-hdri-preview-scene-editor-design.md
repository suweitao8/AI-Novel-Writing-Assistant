# HDRI 预览复用场景编辑器设计

## 背景

通用资产页的 HDRI 3D 预览目前独立创建 PlayCanvas 应用、相机轨道和指针事件，导致它与漫剧场景 3D 编辑器的交互和环境显示逐渐分叉。相同的 HDRI 环境应该由同一套场景编辑运行时负责渲染，否则投射中心、半球尺寸、相机边界和后续修复会出现两套行为。

## 目标

- 通用资产 HDRI 的 3D 预览复用漫剧场景编辑器的 `createBlocking3dViewer` 及其环境运行时、相机导航和编辑器布局。
- HDRI 预览只显示环境，不加载代理角色、场景标记或道具。
- 用户可在 3D 预览中直接编辑环境参数；半球直径的可调范围统一为 5–30 米。
- 资产列表只展示资产名、全景图 2D 预览和进入 3D 预览的操作，不暴露内部 HDR 资源路径。
- 2D 预览使用可浏览器直接显示的全景 PNG，并支持弹窗放大、Escape 和遮罩关闭。
- 继续兼容已有 `domeRadius` 数据和动画预览等内部调用方，避免数据库迁移或破坏旧布局。

## 交互与数据约定

### 3D 预览

HDRI 预览使用与场景编辑器相同的 `Drama3DEditorShell`：左侧对象列表只保留“世界”和环境属性，右侧为 PlayCanvas 场景视口。场景环境的水平旋转保持系统统一值 0，环境亮度保持 1；用户只编辑投射中心高度、分界线和半球直径等已有环境参数，其中半球直径输入始终是整数 5–30。

环境预览通过 `loadProxyActor: false` 创建共享 viewer，禁止为了预览加载代理角色。通用 HDRI 3D 预览适配器只负责 preset/直径到 viewer 环境设置的映射，不再复制相机、拖拽、滚轮和 PlayCanvas 应用初始化。

### 2D 全景图

每个 HDRI 预设新增 `previewImageUrl`，对应仓库内生成的静态 PNG。通用资产表格的图片按钮使用该 URL，按钮可访问名称为“{资产名} 2D 全景预览”；点击打开 `Dialog`，在大尺寸容器中显示图片，使用现有 Dialog 的焦点管理、Escape 和关闭按钮能力。

### 兼容性

`domeRadius` 继续作为场景布局和 API 的兼容字段使用；本次不修改数据库结构。5–30 的统一范围由共享归一化函数和 UI 的 `min`/`max` 同时约束。旧数据超出范围时归一化到边界，坏值回退到默认值。内部需要真实水平半径的调用方继续通过现有换算函数获取，不能自行重复换算。

## 非目标

- 不改变 HDRI 资源文件本身或场景数据库结构。
- 不把角色、道具或动作预览迁移到场景编辑器；本设计只统一通用 HDRI 预览的环境视口。
- 不增加全景图的交互式 360 浏览器；2D 预览就是平面全景图，3D 投影仍由共享场景视口负责。

## 验收标准

1. 契约测试证明 HDRI 预览不再直接创建独立 PlayCanvas 应用或注册独立 pointer/wheel 相机逻辑，而是调用共享 blocking viewer 的无代理模式。
2. 通用资产页不显示 `.hdr` 资源路径，显示资产名、PNG 全景预览和 3D 预览入口；点击图片可打开和关闭放大弹窗。
3. HDRI 3D 预览使用场景编辑器壳层，环境可切换，半球直径滑块的 `min=5`、`max=30`、`step=1` 可用，并能更新共享 viewer。
4. 模型/动画预览与场景编辑器的现有环境加载、类型检查和焦点测试不回归。
5. 在隔离浏览器中访问通用资产页和 HDRI 预览页，完成图片放大、关闭、进入 3D、切换环境、滑块边界和复位视角操作，无新增控制台错误或失败请求。
