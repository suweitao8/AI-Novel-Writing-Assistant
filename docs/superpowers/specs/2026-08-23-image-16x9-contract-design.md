# 图片画幅统一为 16:9 设计

## 背景

漫剧视频预览使用 1280×720，最终成片使用 1920×1080，二者都要求严格 16:9。当前统一规格表中，角色设计稿和角色/道具资产仍使用 1536×1024（3:2），只有分镜首帧使用 1536×864（16:9），会让资产参考图与分镜画面出现画幅不一致。

## 决策

除场景全景图外，所有漫剧生产和设计参考图片统一使用 16:9：

- 角色设计稿、角色状态图：1536×864。
- 角色资产、道具资产：1536×864。
- 漫剧分镜首帧：1536×864。
- 场景 360° 等距柱状全景图：继续使用 2048×1024（2:1）。
- 视频预览/成片仍分别使用 1280×720 与 1920×1080；图片和视频之间保持 16:9，不改变时间轴。

`server/src/services/image/imageSpecs.ts` 继续作为唯一尺寸来源，业务服务不得重新硬编码尺寸。资产默认路由继续使用 Codex，以便角色/道具透明底和场景 2:1 能力与目标画幅一致；Grok Build 的 1280×720 输出仍属于 16:9，但不承担需要透明底或 2:1 的资产任务。

## 兼容与迁移

这次只改变后续生成的目标规格，不自动重采样或删除已有图片。已有 3:2 资产需要用户重新生成后才会变成新的 16:9 画幅；旧图片仍可作为参考图读取。

## 验收

- 规格契约测试断言角色、道具、分镜均为 16:9，只有场景全景为 2:1。
- 角色状态、角色设计稿、场景、道具、分镜入口继续从 `IMAGE_SPECS` 取尺寸。
- 服务端聚焦测试、视频包测试、类型检查和构建通过。
- 更新图片规格架构文档、漫剧工作流说明和用户可见 release note，明确资产与分镜的统一画幅。
