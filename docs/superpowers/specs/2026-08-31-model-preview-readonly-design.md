# 模型库详情页只读预览设计

## Background

模型库详情页当前复用了 3D 编辑器的变换能力：页面显示环境直径滑杆、Transform 面板和变换 gizmo，模型可以被拖动、旋转或缩放。这样模型详情页同时承担了查看和编辑两种职责，模型信息也只展示文件、格式和文件大小，无法判断模型的几何复杂度与真实尺寸。

模型详情页使用的 HDRI 已经由通用资产设置提供。通用资产页负责设置预览环境的来源和参数，模型详情页只应消费这份设置，不能再提供第二套可修改入口。

## Goals

1. 在模型信息中显示加载后模型的顶点数量。
2. 在模型信息中显示模型的米制包围盒尺寸：长（X）、宽（Z）、高（Y）。
3. 在 3D 画面中绘制包围模型的非交互线框盒，使尺寸信息与画面中的模型范围一致。
4. 把模型详情页收敛为只读预览：模型本身不能被旋转、位移或缩放，不显示 Transform 面板和变换 gizmo。
5. 移除模型详情页的预览环境参数控件，环境仍使用通用资产设置中的 HDRI 与参数。
6. 保留只影响相机视角的聚焦、复位视角、快照和相机导航，避免影响模型查看效率。

## Non-goals

- 不修改通用资产 HDRI 设置页的环境参数能力。
- 不把模型顶点数或包围盒写回数据库，也不新增资产字段；这些值由当前加载的 GLB 实时计算。
- 不改变模型库缩略图、动画预览或漫剧场景编辑器的可编辑能力。
- 不允许通过隐藏 UI 之外的旧 API 继续改变模型详情页中的模型变换；模型查看器接口同步移除详情页不需要的变换方法。

## Design

### Geometry statistics contract

模型资源实例化并完成层级同步后，遍历所有 render mesh instances：

- 包围盒使用每个 mesh 的局部 AABB 经节点世界矩阵变换后的 8 个角点求并集，确保 GLB 子节点的偏移和旋转不会被忽略。
- 顶点数按唯一 vertex buffer 去重后累加 `getNumVertices()`。同一缓冲区被多个 mesh instance 复用时只计算一次，避免重复统计实例而夸大复杂度。
- X 轴尺寸作为“长”，Z 轴尺寸作为“宽”，Y 轴尺寸作为“高”；三轴尺寸统一乘以模型的 `unitScale`，页面显示米制值。
- 没有可渲染网格时，模型加载仍按现有错误流程结束，不显示伪造的 0 顶点或 0 尺寸。

查看器返回只读 `geometryStats`，页面在查看器完成加载后再显示统计值。数值格式固定为最多两位小数并去除无意义的尾零；顶点数使用本地化整数格式。

### Bounding box visualization

模型自动按米制单位缩放并把底部中心落到原点。查看器在每一帧用 PlayCanvas 的即时绘制 API 绘制该最终显示空间中的 AABB 线框：

- 线框只作为视觉标记，不加入模型层级，不参与拾取，不提供拖拽目标。
- 线框与模型使用同一组 `bounds`、`unitScale` 和落地偏移计算，不能另行估算尺寸。
- 快照导出时保留模型本身和环境画面，但不绘制交互 gizmo；当前只读模式不会有 gizmo。

### Read-only interaction boundary

模型详情页移除：

- `预览环境` 区块、半球直径滑杆、环境切换状态与详情页环境变更回调。
- `Transform` 面板、变换工具栏、变换回调和模型变换读写 API。

查看器仍保留右键环绕视角、中键平移视角、滚轮缩放视角、键盘相机导航，以及聚焦/复位视角/快照按钮。这些操作只改变相机，不改变 `modelRoot` 的位置、旋转或缩放。底部提示改为只描述视角操作，避免把相机操作误认为模型编辑。

模型详情初始化时继续读取系统通用资产的 HDRI 预设与直径偏好，并传给环境运行时；该值只用于装配环境，详情页不提供 setter，也不保存新的环境值。环境参数的修改入口仅保留在通用资产 HDRI 预览页。

## UI arrangement

左侧“模型信息”保留原有文件、格式、大小三行，并增加：

- 顶点数量
- 长
- 宽
- 高

右侧保持 3D 预览画布；画布中显示模型、通用 HDRI、地面网格和包围盒线框。左侧底部保留聚焦、复位视角、快照三个相机操作按钮。

## Failure handling

- 模型仍未完成加载时，统计行不显示旧值，沿用现有加载状态。
- 统计不可用时显示“暂无数据”，不阻止模型查看；模型没有网格的情况仍由加载错误覆盖层提示。
- HDRI 加载失败沿用查看器现有错误处理，不增加详情页环境重试或编辑入口。
- 包围盒只依赖当前模型资源；材质异步回填不会改变几何统计或线框范围。
