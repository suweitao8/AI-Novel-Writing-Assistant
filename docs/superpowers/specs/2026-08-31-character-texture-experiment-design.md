# 角色模型纹理实验设计

## 背景

模型库目前只有家具、装饰、灯具、厨房、地面、植物和自然分类。分镜 3D 草图、动画预览和动画缩略图使用同一份 UAL2 角色模型，并通过共享的蓝色代理材质显示。

用户希望在模型库增加一个独立的“角色”分类，把这份固定的 UAL2 模型放进去，单独验证给角色做人物外观的可行性；这次实验不能改变分镜、动画或其他代理角色仍使用蓝色材质的行为。

检查发现 `UAL2_UE_Anims.glb` 虽然声明了 `TEXCOORD_0`，但两个网格原语的 UV 坐标全部退化为 `(0, 1)`，且 GLB 没有内嵌图片。因此直接把一张普通人物图片作为 `diffuseMap` 会让整个模型采样同一个像素，不能作为有效的纹理实验。

## 目标

1. 在模型库新增“角色”分类，并加入一个使用现有 UAL2 GLB 的“男大学生（纹理测试）”条目。
2. 角色条目在模型库缩略图和模型详情 3D 预览中默认使用一套可见的男大学生测试外观。
3. 角色详情页可以在“测试纹理”和“蓝色基准”之间切换，便于判断模型上色前后的差异。
4. 其他模型库条目、分镜 3D 草图、动画预览和动画缩略图继续使用现有蓝色代理材质，不读取角色实验外观。
5. 保留现有变换、HDRI 环境、快照导出和模型加载错误处理，不为这次实验引入数据库或服务端状态。

## 方案

### 1. 目录与复用边界

- 在 `ModelLibraryEntry` 增加可选的预览外观标记；普通模型不设置该标记。
- 新角色条目复用 `ModelLibraryPage`、`ModelEditorPage`、`thumbnailStudio` 和 `createModelViewer`，不另造一套模型库页面。
- 角色条目指向已有 `/anims/cine57/UAL2_UE_Anims.glb`，不复制模型文件，也不把动画文件改造成新的运行时资产。
- 分镜与动画入口继续直接调用 `setEntityMaterial(model, BLOCKING_3D_BLUE_ACTOR_COLOR)`，不经过角色实验外观控制器。

### 2. 角色测试外观

新增模型库 3D 专用的角色外观控制器。控制器只接受 `blue` 与 `male-college-student` 两种模式：

- `blue` 使用共享蓝色代理常量，确保对比基准和旧路径一致。
- `male-college-student` 在浏览器内生成一张 2D 颜色纹理，并通过对象空间圆柱投影采样它。纹理包含头发、肤色、校园上衣、牛仔裤和鞋子的分区及细微布料变化；它是本次“能否给固定模型上色”的验证材质，不冒充已经完成 UV 展开的生产纹理。
- 因为当前 GLB 的 UV 无效，着色器不读取 `TEXCOORD_0`，而是根据模型已落地到米制坐标的 `vPositionW` 推导环向 `u` 和高度 `v`。这样仍能验证外部纹理和材质切换链路，同时避免把错误 UV 带入分镜或动画。
- 控制器负责生成纹理、创建材质、切换 mesh instances，并在模型查看器销毁时释放材质与纹理。

### 3. 详情页交互

角色条目详情页的侧栏增加“角色外观”区块，仅在该条目存在预览外观标记时显示：

- 默认选中“测试纹理”，3D 视口直接展示男大学生测试外观。
- 点击“蓝色基准”立即切回蓝色代理；点击“测试纹理”重新套用测试材质，不重新加载 GLB 或 HDRI。
- 切换按钮使用现有 `Button` 组件和语义色 token；切换期间控件保持可用，失败时通过现有 `toast.error` 告知用户。
- 当前选择只属于模型详情页的实验预览，不写数据库、不改变共享角色代理，也不改变其他页面。

### 4. 缩略图

角色卡片缩略图复用同一外观控制器并默认使用测试纹理，确保用户在点击卡片前就能看到角色分类的实验结果。现有普通模型缩略图仍只应用各自 `materials` 回填。

## 数据流

```text
MODEL_LIBRARY[角色条目]
        │ previewAppearance = character-texture-test
        ├── ModelLibraryPage → thumbnailStudio → 角色测试外观 → 卡片缩略图
        └── ModelEditorPage → createModelViewer
                              ├── 角色外观切换
                              └── 3D 视口中的测试纹理/蓝色基准

分镜 blocking3d / 动画预览 / 动画缩略图
        └── 继续直接使用 BLOCKING_3D_BLUE_ACTOR_COLOR
```

## 错误与生命周期

- 角色 GLB 仍由现有 `loadAsset` 加载；加载失败沿用模型编辑器错误状态和资源销毁路径。
- 测试纹理只在角色模式首次需要时创建；纹理或材质创建失败时保留蓝色基准，不影响模型库其他条目。
- 角色详情页卸载、切换路由或模型查看器销毁时，释放角色实验材质和生成纹理，避免 WebGL 资源泄漏。
- 普通模型的 `materials` 回填路径保持原样；角色实验外观不修改共享 `applyModelMaterials` 的行为。

## 非目标

- 本阶段不重新导出 UAL2 GLB，不做正式 UV 展开，不修改骨骼、动画或模型几何。
- 本阶段不接入服务端 AI 生图任务、不保存提示词、不引入角色纹理数据库。
- 本阶段不改变分镜、动画、缩略图的蓝色代理显示。
- 本阶段不声称测试材质已经达到可直接用于最终图生图的生产级纹理质量；最终生产纹理需要有效 UV 和专门的纹理生成/校验流程。

## 验收标准

1. `/models` 出现“角色”页签，数量为 1，并显示“男大学生（纹理测试）”卡片。
2. 角色卡片能生成非蓝色的男大学生分区外观缩略图；普通模型卡片行为不变。
3. 角色详情页能加载 UAL2 模型，默认显示测试纹理，且“测试纹理/蓝色基准”切换会即时改变 3D 模型外观。
4. 分镜 3D 草图、动画预览和动画缩略图仍匹配蓝色材质常量。
5. 定向契约测试覆盖分类、角色条目、隔离边界和切换入口；客户端类型检查、构建及内置浏览器烟测通过。
