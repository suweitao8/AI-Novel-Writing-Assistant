# 漫剧分镜 3D 草图静态环境设计

## Background

当前分镜行同时暴露二维摆位草图和独立 3D 摆位台。3D 页面仍把场景图铺成后置平面，角色代理也会循环播放动画；这与分镜需要的“静态构图参考”不一致，且用户必须在两个入口之间判断该使用哪套工具。

## Decision

1. 分镜工作台只保留一个「3D 草图」入口，点击后进入现有独立 3D 路由。二维编辑器不再作为用户功能展示；旧的服务端数据、PNG 读取和确认接口继续保留，确保已有确认草图仍可被分镜生成链消费。
2. 角色姿势仍从 Quaternius 动画资源中取一个代表帧，但运行时始终暂停在该帧。移除播放/暂停控制；新建、载入和保存的布局都强制 `actionPlaying: false`，旧快照里的 `true` 只作为兼容输入并在归一化时变为静态状态。
3. 场景状态图作为 2:1 等距柱状环境图贴到 PlayCanvas `DomeGeometry` 半球内部，使用反向剔除和自发光材质，随相机移动保持为远景环境。移除后置矩形背景平面，不把场景图当作普通墙面。
4. 3D 草图仍按现有流程保存 `layout3d`、捕获 1280×720 PNG、上传并确认；PNG 继续作为分镜生成的首位锁定参考图。

## Boundaries

- 不删除 `blockingSketchData` 数据列、服务端解析/保存/确认接口或已有 PNG 文件；这些是历史项目和分镜生成链的兼容边界。
- 不把真实角色资产转换为可驱动 GLB；3D 代理只用于构图、深度、相机和静态姿势预演。
- 不新增 UI 库或颜色；页面继续使用现有 Button、Card、Badge、SelectControl、toast 和语义 token。

## Acceptance

- 分镜列表源代码只有「3D 草图」入口，不再渲染二维草图按钮或 `ShotBlockingSketchDialog`。
- 3D 页面没有播放/暂停动作控件，角色动画只用于取样后停帧；导出的每个 actor 都是静态状态。
- viewer 使用 DomeGeometry/HDRI 环境实体，不创建 `blocking3d-background` 平面。
- 旧确认 PNG 仍可被读取并作为首帧参考；新 3D 草图保存、确认和返回分镜流程不变。
