# 模型透明叶片双面渲染设计

## 背景

模型目录中的草、花和其他镂空叶片通常由带 alpha 的薄片组成。模型详情页和分镜前景都会通过 `modelMaterials.ts` 重新创建 PlayCanvas `StandardMaterial`，但新材质沿用默认的背面剔除规则。当前 `wildflower-c` 的真实预览已复现为只显示朝向相机的一侧，背向相机的叶片面被剔除。

## 决策

把目录材质中的 `opacity` 映射作为“透明镂空表面”的统一渲染信号。共享材质构建器在该信号存在时设置 `material.cull = pc.CULLFACE_NONE`，使透明叶片、草片和花瓣从正反两面都可见；没有 `opacity` 的普通不透明材质继续使用默认的背面剔除。

该规则放在 `applyModelMaterials` 的共享入口，因此同时覆盖模型详情预览、模型缩略图和分镜前景模型，不需要给每个草模型增加独立的运行时补丁，也不改写 GLB 几何或贴图文件。

## 数据流与边界

1. 目录材质映射声明 `opacity`。
2. `applyModelMaterials` 加载 opacity 贴图并配置 alpha test。
3. 同一分支关闭背面剔除，得到双面 alpha-cutout 材质。
4. 详情页、缩略图和分镜继续复用该材质。

本次不把所有模型统一改为双面，也不改变透明度阈值、深度写入、贴图 alpha 语义或导入准入门禁。只有明确声明镂空贴图的材质启用双面渲染。

## 验证

- 单元测试验证带 `opacity` 的材质策略返回双面，普通材质不返回双面。
- 客户端类型检查通过。
- 在真实 `/models/wildflower-c` 详情页确认草叶从相反视角仍完整显示，控制台无错误；同时确认缩略图和分镜共享入口没有回归。
