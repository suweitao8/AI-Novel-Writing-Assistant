# 动画目录细分类与分页设计

日期：2026-08-31

## 背景

动画页当前把 UE 资产按来源组、套装、动作类型三层展示。入口页同时挂载全部卡片，导致首屏初始化大量缩略图；武器、姿态和生物动作的真正语义又只藏在套装名称或片段名里，分镜草图用户很难快速找到可用动作。

UE 扫描清单已经提供真实 Asset Registry 路径、源骨架和片段名。当前选入统一 UAL2 GLB 的 402 个 UE 片段中，已经包含弓箭、长枪与戟、剑、武士刀、刺剑、双刃、手枪、重锤、镰刀、匕首，以及恶魔、僵尸、幽灵、怪物和生物地面动作。此次重点是把这些事实编入策选元数据并改善入口页，不在运行时根据文件名猜分类。

## 决策

### 1. 用户可见的目录层级

- 顶部来源入口固定为「全部、旧动画、日常动作、日常互动、生活与表演、徒手战斗、武器战斗」。UE 来源组的可见名称不再添加「虚幻」前缀。
- 页面只保留两行筛选：第一行是来源大类，第二行是当前大类下的规范化细分类。套装仍作为卡片元数据和搜索字段，不再占用独立的主导航层。
- 不增加“查看具体分类”或重复的分类详情页；点击分类后直接展示结果卡片。

### 2. 静态分类契约

每个动画条目必须携带以下策选字段：

- `classificationId` / `classificationLabel`：页面第二行使用的稳定细分类，例如 `bow`/「弓箭」、`spear`/「长枪与戟」、`crouching`/「蹲伏」、`ground-creature`/「生物地面动作」。
- `actorKind`：`human`、`humanoid-creature`、`monster` 或 `paired`，用于区分普通人形、可复用人形骨骼的怪物/生物和配对动作。
- `posture`：`standing`、`crouching`、`sitting`、`kneeling`、`lying`、`crawling`、`airborne` 或 `mixed`。
- `weaponType`：`none`、`barehand`、`sword`、`katana`、`rapier`、`spear`、`dual-blade`、`bow`、`pistol`、`hammer`、`scythe`、`dagger`、`magic` 或 `mixed`。

字段由 UE 策选清单显式提供：套装给出默认语义，混合套装在单个片段上声明覆盖值。生成器只负责校验并传递字段，前端不解析中文名、英文文件名或路径来推断分类。

### 3. 分类范围

- 日常动作：站立待机、站立移动、蹲伏、坐姿、躺卧/睡眠、翻滚/闪避、跳跃/翻越、对话/手势。
- 日常互动：站立互动、蹲伏互动、坐姿互动、制作/采集、车辆互动、游泳/桌面互动。
- 生活与表演：移动、反应/求饶、地面动作、配对互动、表演/手势、攀爬、受伤/恢复、祈祷/演讲、舞蹈。
- 徒手战斗：基础徒手、拳击、泰拳、咏春、忍者、能量特技、终结技，以及恶魔、僵尸、幽灵、怪物、生物地面、生物攻击、飞行法师等生物/法术细类。
- 武器战斗：剑、武士刀、刺剑、长枪与戟、双刃、弓箭、手枪、重锤、镰刀、匕首、法师武器。

“狼人”只在扫描证据出现明确的狼人资源时新增独立分类；当前清单没有该名称的真实片段，因此相关怪物动作统一归入已有的怪物/生物细类，不把普通人形动画误标为狼人。

### 4. 分页和交互状态

- 默认每页 24 张卡片，分页切片发生在卡片组件挂载之前，避免未显示的条目启动缩略图生成。
- 搜索、来源组和细分类任一变化都将页码重置为第 1 页；结果为空时显示空状态而不显示无效分页。
- 分页控件提供上一页、下一页、当前页/总页数和总结果数；第一页/最后一页对应按钮禁用，按钮具备可读的 aria 标签。
- 搜索保留，匹配条目名称、片段名、套装、分类标签和源资产元数据。

## 数据流

`animationCatalogSelection.json`（真实 UE 路径 + 显式 taxonomy）
→ `build_animation_catalog_selection.cjs`（存在性、Mannequin 骨架、字段完整性校验）
→ `generate_animation_catalog_entries.cjs`
→ `animationLibrary.ts`（旧动画补齐兼容分类）
→ `AnimationLibraryPage.tsx`（两行细分类筛选 + 24 条分页）

分类字段只影响目录元数据和页面筛选；若本次没有新增片段，则不重建已有 GLB。统一 GLB 仍是 UAL2 角色与动作的实际播放资源，新增片段时才按 UE 导出、离线重定向和 GLB 内容门禁重新生成。

## 验收标准

1. 页面不出现“虚幻 ·”可见标签；不再出现套装下拉或重复的具体分类入口。
2. 筛选区域在桌面和窄屏都保持两行可横向浏览的紧凑分类条。
3. 默认页面只挂载 24 张卡片；翻页、筛选和搜索均正确更新结果并回到第 1 页。
4. 自动化检查能证明选入条目覆盖武器子类、姿态分类和怪物/生物分类，且每条记录都有合法字段与真实 UE 路径。
5. 内置浏览器能打开动画页、筛选武器/生物细类、翻页并进入预览，控制台无错误。
