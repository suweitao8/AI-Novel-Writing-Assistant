# 漫剧 3D 草图 HDRI 视口与角色基础打光设计

## 背景

HDRI 草图视口已经支持环境贴图、投射中心和半球尺寸，但地面半球的几何在中心区域使用了不连续的压平规则，尺寸变化时会形成圆形波纹。中键平移也使用了固定世界轴，拖拽方向与 Unreal 用户习惯相反。当前环境面板还暴露了不需要用户调节的水平旋转和亮度。

## 决策

1. 面板只保留两个可调参数：投射中心高度默认 `3`、范围 `1–10`；半球直径默认 `20`、范围 `10–50`。水平旋转固定为 `0`，环境亮度固定为 `1`，不再显示这两个控件；保存的旧四字段数据继续兼容，但加载和导出时归一化为固定值。
2. 普通场景图的地面半球改为连续的浅碗形曲面。地面边缘高度与投射中心高度和半球尺寸联动，使边缘始终处于投射中心下方，不再使用中心圆形硬阈值，也不使用把一整圈点压到同一个 UV 高度的截断逻辑。改变半球直径只改变覆盖范围，不产生移动的环形折线。
3. 中键平移按摄像机的屏幕右轴和屏幕上轴计算世界位移，拖拽方向遵循“场景跟随鼠标”的 Unreal 风格；不再把水平位移硬编码到世界 X 轴。
4. 加载场景图后，从图像上方区域的高亮像素估算主光方向和暖色。方向只作为视口角色的基础方向光，不写入用户布局参数；无法读取像素时使用稳定的中性斜上方后备方向。环境贴图仍负责背景显示，方向光只补足角色的可读性。

## 验证

- 契约测试覆盖新的默认值、边界、隐藏控件、固定 yaw/intensity、连续地面几何和屏幕空间平移公式。
- 纯函数测试覆盖亮部在图像左/右侧时的光源方向变化，以及空图像后备方向。
- 客户端 typecheck、服务端 typecheck、定向测试和完整构建通过。
- 固定端口页面确认只显示两个 HDRI 控件，调整尺寸时无控制台错误；加载普通场景图后角色出现基础方向光，旧布局的 yaw/亮度被固定归一化。
