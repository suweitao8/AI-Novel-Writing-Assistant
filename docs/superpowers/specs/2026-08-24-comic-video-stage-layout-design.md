# 漫剧视频阶段界面整理设计

## Background

当前漫剧工作室的「视频」页已经拥有完整的整集合成能力，但合成设置、进度、结果统计、字幕下载和视频预览全部堆在同一层级。用户难以判断“字幕烧进画面”和“片头片尾卡”分别会影响什么；视频预览还被 `max-w-3xl` 限制在中间，无法利用工作区宽度；页签右上角的“打开视频工作台”会跳转到旧的 `/drama/projects/:id` 页面，和当前漫剧工作室的工作流重复。

## Goals

- 让视频页按用户决策顺序呈现：先选合成设置，再看合成状态，最后播放和下载结果。
- 用面向用户的文案解释字幕和片头片尾选项，不改变现有 API 语义。
- 让已生成视频在当前内容区横向铺满，同时保持 16:9 比例和原生视频控件。
- 移除当前视频页指向旧视频工作台的入口，避免用户进入另一套不一致的流程。
- 保留现有轮询、失败提示、字幕下载、外部打开和其他旧页面消费者。

## Design

### 1. 合成设置

`DramaEpisodeAssemblyResultPanel` 的设置区域改为带标题的响应式网格，每个设置项都由复选框、主标签和简短说明组成：

- `字幕写入视频`：开启时字幕直接显示在视频画面中；关闭时仍生成可下载的 SRT 字幕文件。
- `片头和片尾`：开启时加入显示本集标题的片头和“敬请期待下集”的片尾。

合成进行中两个选项保持禁用，避免用户误以为正在运行的任务会实时切换配置。合成按钮位于设置区域右侧或下一行，沿用现有 `DramaEpisodeAssemblyButton` 状态和禁用逻辑。

### 2. 进度与错误

运行中继续显示当前阶段、百分比、片段进度和降级数量，但使用独立的“合成进度”区块；错误继续使用独立的错误区块并保留重新合成入口。现有状态数据和 toast 不变。

### 3. 视频预览与结果信息

生成完成后使用“视频预览”区块：视频元素为 `w-full aspect-video`，移除最大宽度限制和水平居中约束，外层负责圆角、边框和溢出裁切。播放控件仍使用原生 `<video controls>`，不引入新的播放器依赖。

预览下方使用“视频信息”响应式网格展示时长、镜头数、字幕状态和生成时间；字幕下载和新窗口打开作为独立操作行，警告单独放在信息区之后，避免和主要操作混在一起。

### 4. 旧视频工作台入口

删除 `ComicDramaStudioPage` 视频页签右上角的“打开视频工作台”按钮及不再使用的图标导入。保留 `DramaProjectPage` 路由及其他页面现有入口，因为旧短剧项目页仍可能服务历史项目；本次只移除当前漫剧工作室中的歧义入口。

### 5. Responsive / Accessibility

- 设置项在窄屏单列、宽屏双列；视频始终不小于容器宽度并保持 `aspect-video`。
- 复选框继续使用原生可键盘操作控件；标签和说明放在同一可点击 label 内，合成中同步 disabled。
- 所有新增操作继续复用现有 `Card`、`Badge`、`Button` 和语义颜色 token，不添加硬编码颜色或新的 UI 依赖。

## Scope Boundary

本次不修改合成请求字段、服务端片头片尾内容、字幕生成逻辑、旧项目页的数据加载和路由；只调整当前漫剧视频页的展示结构、文案和入口。

## Acceptance Criteria

1. 视频页能清楚区分“合成设置”“合成进度”“视频预览”“视频信息”。
2. 字幕和片头片尾选项的文案能直接说明开启后的效果。
3. 视频预览不再受 `max-w-3xl` 限制，桌面端横向铺满内容区，窄屏不溢出。
4. 当前漫剧视频页不再出现“打开视频工作台”入口，旧页面路由仍可被其他流程使用。
5. 运行中、失败、完成、无结果和下载字幕等既有状态继续可用。
6. 相关契约测试、客户端类型检查和真实浏览器页面回归通过。
