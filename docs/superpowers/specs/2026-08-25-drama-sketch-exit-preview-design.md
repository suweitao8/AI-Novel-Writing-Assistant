# 分镜 3D 草图自动保存与 AI 预览来源隔离

## Background

当前分镜页已经提供 3D 草图编辑、草图/AI 图切换和独立图片接口，但两个边界行为不完整：

1. 3D 草图编辑页点击返回时只弹出“是否离开”的确认框，没有把当前 viewer 快照和 PNG 自动保存下来，因此分镜页不能可靠地拿到最后一次摆位。
2. 第 1～3 镜的 `keyframeData` 虽然标记为 `done`，浏览器请求的仍是各自的 keyframe 地址，但落盘字节与“末世血角兽猎场”场景状态图完全一致。也就是说参考图被当成了 AI 首帧结果保存，前端没有机会知道这是无效首帧。

## Goals

- 从 3D 草图编辑页离开时，若有未保存修改，自动完成“保存 JSON 草稿 + 上传 PNG”，保存成功后再返回分镜。
- 保存后让分镜页重新读取项目数据，并通过 `generatedAt`/版本参数使同一路径的 PNG 不被浏览器缓存为旧图。
- 在统一图片生成 runtime 中拒绝与参考图字节完全相同的结果，让该次生成进入 `error`，不再写入 `done`。
- 对已有的历史异常 keyframe，在图片接口层识别并拒绝直接输出参考图；分镜卡片在图片加载失败时显示“暂无可用 AI 画面”和重新生成入口，不显示场景图或破图。
- AI 图和 3D 草图都保持独立来源；切换 tab 只改变当前预览，不改变任何持久化数据。

## Non-goals

- 不删除或覆盖现有用户图片和历史版本。
- 不自动重新生成现有第 1～3 镜的 AI 图；它们会被明确标记为不可用，用户可在对应卡片点击“重新生图”。
- 不改变分镜、3D 草图或视频合成的分辨率契约。

## Design

### 1. 退出保存

将 3D 草图保存函数改为返回成功/失败结果。返回动作变为异步流程：

```text
有未保存修改
  → 禁用交互并显示保存中
  → 保存 layout3d/角色摆位 JSON
  → 捕获并上传 PNG
  → 刷新 drama project 查询
  → 保存成功后 navigate(-1)
保存失败 → 留在编辑页，保留未保存状态并显示错误
```

编辑页上的显式返回按钮、WebGL 错误页返回按钮和无场景状态返回按钮共用这个流程。保存中的重复返回操作被忽略；浏览器关闭仍保留 `beforeunload` 提示，因为关闭页面无法可靠等待异步上传。

### 2. 草图图片回灌

分镜卡片继续以 `blockingSketchData.url` 作为 3D 图唯一来源，不读取 `blockingSketchData.scene.imageUrl` 作为预览。预览 URL 追加草图 `generatedAt`（无时间戳时使用版本）作为缓存参数，确保同一接口路径替换 PNG 后立即显示新快照。

### 3. AI 首帧完整性

参考图准备阶段为实际发送的附件计算 SHA-256 指纹，并把指纹随 provider 结果返回给 runtime。runtime 下载生成结果后先比较指纹，再落盘：

- 命中任意参考图：抛出“生成结果与参考图完全相同”的可读错误，写入 `error` 状态，保留重新生成入口。
- 未命中：沿用现有落盘、版本和状态流程。

图片服务对已有 `done` 数据在输出前进行同样的字节比对；命中时返回 404，而不是把参考场景图作为 keyframe 输出。服务端使用文件大小/修改时间做进程内缓存，避免同一图片反复下载参考图。

### 4. 前端缺图状态

`LightboxImage` 增加图片加载失败回调。分镜卡片收到 keyframe 404 或加载失败后，将该镜的 AI 预览切换为明确的空态，并保留“重新生图”按钮。AI 图 URL 和 3D 图 URL 都带生成版本参数，避免重生成或重新保存后继续读取旧缓存。

## Interaction and accessibility

- 保存/确认/返回按钮在保存期间禁用并显示加载状态。
- 预览 tab 继续使用 `role="tab"`、`aria-selected`、方向键切换和 `aria-controls`。
- AI 图片不可用时空态使用 `role="status"`，不会把场景图误当作成功结果。

## Verification

- server runtime 回归：生成结果与参考图相同必须失败并持久化 `error`。
- client 合同回归：返回动作等待保存成功、查询刷新、预览 URL 具备版本参数、图片失败显示空态。
- server/client 定向 typecheck/build 与现有测试。
- 使用内置浏览器验证：编辑 3D 草图后返回，分镜 3D 图更新；第 1～3 镜 AI tab 不再显示场景图，异常时显示空态。
