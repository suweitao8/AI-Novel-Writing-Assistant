# 女性旁白音色提示词优化设计

## 背景

当前系统旁白使用 VoxCPM2 的 Voice Design 模式生成试听。上一轮已经隔离了“新音色设计”和“上一轮试听样本克隆”：没有用户明确参考音频时，生成请求不会携带 `audio_url`。当前女性旁白描述只有“成年女声、普通话、温和沉稳”等宽泛信息，实际试听容易出现声音偏平、距离感不足、播音感或气质不稳定的问题。

## 目标

- 让系统默认女性旁白更接近真实人物讲故事的听感。
- 明确年龄区间、女中音音域、亲和度、语速、停顿、吐字和自然表现，减少模型自由发挥造成的音色漂移。
- 保持无参考音频的 Voice Design 语义，上一轮试听样本不能隐式变成新设计的参考音频。
- 保持用户可以自行编辑提示词并生成其他风格旁白的能力。

## 决策

采用“自然亲和、真实讲故事”的女性成年女中音方向，推荐描述为：

> 成年女性，约30岁，明亮自然的女中音；普通话标准清晰，声音温暖亲和，像真实的人在近距离讲故事；语速中等，停顿自然，句尾平稳但有轻微语气变化；吐字清楚、连贯，有真实呼吸感；不要播音腔、主持腔、新闻腔，不要低沉或男性化。

提示词只作为旁白音色设计的 `emotion_prompt` 进入现有音频适配层。不得新增固定性别匹配、关键词路由或上一轮样本回退逻辑。

## 影响范围

- 默认女性旁白描述：更新为空设置时返回的默认值和设置页示例占位符，使首次使用和手动填写时都得到同一方向的引导。
- 现有已保存描述：不强制覆盖用户已经保存的自定义描述；用户点击“重新生成并试听”时，使用当前文本。
- 音频链路：不改 `referenceAudioUrl` / `sampleAudioUrl` 的语义和 Voice Design 数据流。
- 文档：补充提示词编写原则和失败模式，说明为什么避免只写“温和沉稳”等抽象词。

## 验证

1. 先用回归测试锁定新的默认描述和设计请求仍只传 `emotion`，无隐式 `referenceAudioUrl`。
2. 运行专项旁白设置测试，确认迁移、保存、清除参考音频和重新设计场景不回归。
3. 运行 shared/server 构建，确认类型和打包通过。
4. 调用当前本地 VoxCPM2 真实桥接生成一次，确认请求为 `audio_type=narration`、无 `audio_url`，返回有效 WAV；记录生成描述和音频基本信息，不把主分支运行数据写入代码。

## 非目标

- 不修改 VoxCPM2 外部桥接模型或推理参数。
- 不新增音色选择器、性别枚举或参考音频上传 UI。
- 不把用户已有自定义旁白提示词静默替换成新的默认描述。
