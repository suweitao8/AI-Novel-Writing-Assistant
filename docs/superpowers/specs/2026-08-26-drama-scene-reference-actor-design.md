# 场景 3D 参考角色校准设计

## Background

场景 3D 编辑器需要一个固定的比例参照来校准 HDRI 的投射中心和半球直径。当前页面仍以约 1.8 米为文案和运行时高度，代理角色的默认横向位置也沿用了多角色分布公式，因此首次进入场景编辑时角色不在世界坐标中心。选择环和角色光照还需要明确符合场景校准用途。

## Decision

- 场景编辑器的固定比例参照角色使用 `1.7m`，页面文案同步显示约 1.7 米。
- 参考角色首次加入时放置在世界坐标原点 `[0, 0, 0]`，其中 `y=0` 表示落地；分镜 3D 草图的多角色默认分布逻辑保持不变。
- 3D 选择环继续使用空心环形几何，不生成中心填充面；选中材质使用半透明绿色（透明度约 50%）并关闭深度写入，避免遮住 HDRI 地面或角色脚部。
- 场景 HDRI 加载后继续通过 PlayCanvas `EnvLighting.generateLightingSource` 和 `EnvLighting.generateAtlas` 写入 `Scene.envAtlas`。角色代理材质显式启用 `useLighting` 与 `useSkybox`，确保 HDRI atlas 参与角色环境光、反射和漫反射明暗；没有 HDRI 时才使用现有的中性环境光兜底。
- 参考角色仍由场景页锁定不可移动，不写入场景资产或分镜布局数据；可选初始位置只作为 viewer 的创建参数，不改变已有 `layout3d` 合同。

## Implementation Boundary

- `DramaScene3DPage` 负责场景专用的 1.7 米常量、文案和中心位置参数。
- `blocking3dViewer` 为 `addActor` 增加可选初始位置；未传入时继续沿用现有分镜多角色默认排布。
- `setEntityMaterial` 显式配置 HDRI 环境光相关材质开关；选择环材质单独使用半透明参数。
- 更新场景 3D 契约测试、选择环材质契约和 HDRI 环境光契约；不新增后端字段或迁移数据库。

## Failure Handling

- 参考角色模型加载失败时沿用现有 3D 预览错误态，不把未加载的角色当作已校准。
- HDRI 加载失败时沿用纯色地面和中性环境光兜底，并保留现有错误提示；不生成伪造的方向光。
- 角色位置和高度只影响当前场景编辑器的视觉校准，不覆盖分镜角色真实身高或已保存的分镜布局。

## Verification

- 契约测试确认场景页传入 `1.7` 米和 `[0, 0, 0]`，分镜页仍使用已有角色身高数据。
- 选择环测试确认空心几何、透明度和关闭深度写入。
- HDRI 测试确认 lighting source、atlas、`Scene.envAtlas` 以及角色材质的 `useLighting/useSkybox` 链路存在，且没有方向光或补光。
- TypeScript 检查和定向单元/契约测试通过后，用浏览器打开场景 3D 编辑器检查角色中心位置、1.7 米文案、半透明圆环和 HDRI 光照效果。
