# 模型库与动画库固定网格设计

## 背景

模型库此前根据窗口可用高度和响应式列数动态计算页大小，动画库虽然每页取 50 条，但网格列数仍随断点变化。窗口宽度或页面可用高度变化后，同一页会出现不同列数和不同总行数，造成窄窗口反而显示更多行、宽窗口反而显示更少行的反直觉结果。

## 决策

模型库与动画库统一采用固定的资产浏览契约：

- 每行固定 10 个卡片。
- 每页固定 5 行，即 50 条数据；最后一页不足 50 条时按实际剩余数量展示。
- 网格使用固定 `grid-cols-10`，不再使用按断点变化的列数。
- 模型库移除按容器高度计算页大小的 `ResizeObserver` 链路，页码只由筛选结果和固定页大小决定。
- 搜索、分类切换、页码边界和缩略图生命周期保持现有行为不变；本次只改变网格布局与分页契约。

这样窗口宽度变化只影响卡片可用宽度，不会改变一页包含的卡片数、列数或行数，模型和动画的浏览节奏保持一致。

## 验证

- 分页纯函数验证固定页大小为 50，51 条数据分为两页。
- 模型页源码验证不再引用动态页大小 hook，并固定使用 `grid-cols-10`。
- 动画页源码验证固定使用 `grid-cols-10` 和 50 条分页。
- 在模型页和动画页分别用宽桌面与窄桌面视口检查计算后的列数为 10、首屏页内卡片数为 50，并检查控制台与网络错误。
