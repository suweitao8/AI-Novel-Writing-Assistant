# 漫剧 3D 草图 HDRI 地面清晰度设计

## 背景

3D 草图目前把场景状态图直接映射到 `DomeGeometry`。场景状态图的实际产物是 16:9 普通场景图，而不是 2:1 等距 HDRI；把它直接用于半球底部会让底部像素集中铺满地面，造成明显拉伸和模糊。当前地面还没有投影高度、半球尺寸、旋转和环境亮度的可调入口。

## 决策

1. 按纹理宽高比区分两种输入：接近 2:1 的素材保留标准等距 HDRI 完整半球采样；其他比例的普通场景图拆成上半球和带同一贴图的下半球，上半球只采样天空/远景，弧形地面网格采样下半幅图像。这样仍然是 EnviroDome 式的圆球地面，而不是把地面降级成平面；同时避免普通透视图被整张硬套到完整半球。
2. 所有环境纹理统一启用线性采样、关闭 mipmap、水平各向异性过滤和边缘寻址；环境材质使用可调的自发光强度，使背景不会被场景灯光改变清晰度和明暗。
3. 环境参数保存在现有 `layout3d` JSON 中，保持 `schemaVersion: 1` 向后兼容。参数范围为：投影高度 0.6–2.0、半球尺寸 24–96、水平旋转 -180–180 度、环境亮度 0.6–1.6。环境实体固定在世界坐标，投影高度只改变半球的竖直比例，地面仍固定在世界 Y=0，避免角色脚底漂移或相机旋转时地面搬动。
4. 3D 草图右侧增加紧凑的 HDRI 环境参数卡，调整立即反映到视口并随保存草图持久化；旧布局没有环境参数时使用默认值。

## 数据流

`scene.imageUrl` → PlayCanvas texture → 纹理质量配置 → 2:1 等距完整半球或普通场景图的上半球 + 带贴图的下半球 → 参数化环境实体 → `layout3d.environment` 持久化。

重新加载布局时先恢复环境参数，再创建场景环境；清空场景图时恢复纯色地面。

## 验证

- 契约测试覆盖普通 16:9 场景图的地面投影分支、真实等距 HDRI 分支、纹理采样配置和参数 API。
- 服务端 schema 和归一化逻辑覆盖环境参数边界。
- 运行客户端定向测试、类型检查和构建。
- 在 3D 草图页面确认：当前场景地面不再整片拉伸发糊；投影高度、半球尺寸、旋转和亮度调整立即生效；保存后刷新仍保持参数；浏览器控制台无新增错误。
