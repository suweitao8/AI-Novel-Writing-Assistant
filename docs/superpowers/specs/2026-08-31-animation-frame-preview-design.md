# 动画帧预览设计

## Background

动画库目前把动作时间以秒传递给详情页、关键帧存储和缩略图工作室。详情页时间轴可以停在任意小数秒，缩略图工作室也使用独立的 40% 秒数取样，因此用户无法确认卡片展示的是动作中的哪一帧，卡片与详情页的预览位置也没有统一合同。

统一动画 GLB 的采样证据表明：旧 UAL2 片段主要按 30 fps 采样，Cine57 导入片段主要按 24 fps 采样。帧单位必须保留这个差异，不能用单一固定帧率伪造帧数。

## Decision

### 1. 帧时间模型

- `AnimationLibraryEntry` 增加 `frameRate`，旧动画为 30，Cine57 导入动画为 24。
- 新增动画帧工具模块，集中定义以下规则：
  - 内部帧索引从 0 开始；
  - 片段最后一帧为 `round(durationSeconds * frameRate)`；
  - 总帧数为最后一帧加 1；
  - 默认预览帧为最后一帧的 50%，四舍五入为整数；
  - 帧索引与秒数的换算统一经过该模块，并在边界处裁剪到有效范围。
- 运行时优先从 PlayCanvas `AnimTrack.inputs` 的采样时间推断帧率，目录中的 `frameRate` 作为可验证的回退值。这样即使未来某个片段的采样率发生变化，也不会静默按错误帧率显示。

### 2. 详情页

- `openAnimationPreview` 的公共控制面改为 `setFrame/getFrame/getFrameCount/getFrameRate` 与 `onFrameChange`，不再向页面暴露以秒为单位的时间轴状态。
- 加载片段后默认定位到 50% 帧；若存在已保存关键帧则恢复该帧。默认定位完成后暂停，让用户看到的“当前帧”稳定可确认；播放按钮仍可继续播放。
- 时间轴 `step` 固定为 1，范围覆盖 `0..最后一帧`，当前帧、总帧数和卡片预览帧说明均使用帧单位，不再显示“秒”。
- 设为预览帧时保存当前整数帧，成功提示也显示帧号。保留恢复默认预览图的操作。

### 3. 卡片缩略图

- 缩略图工作室加载实际动作轨道后，使用同一套帧工具计算该片段的总帧数和 50% 默认帧，再将动画层定位到该整数帧后抓图。
- 卡片继续优先使用用户手动保存的关键帧；没有手动关键帧时使用自动生成的 50% 帧缩略图。
- 因取帧合同变化，动画缩略图缓存版本递增，旧的秒取样缩略图不能覆盖新结果。

### 4. 持久化与兼容

- 关键帧存储升级到新的 schema 版本，以 `frame` 为规范字段，并保存帧率/可换算的兼容信息。
- 读取旧版只保存 `timeSeconds` 的记录时，按当前条目的真实帧率转换为整数帧并迁移到新格式，避免用户已保存的卡片预览无故消失。
- 无法读取或超出范围的记录按无效数据处理，不阻塞动画库加载；重新生成缩略图仍可重试。

## Data flow

```text
目录 frameRate + GLB AnimTrack 采样时间
            ↓
       animationFrame 工具
     ↙                    ↘
详情页帧时间轴              缩略图工作室 50% 帧
     ↓                    ↓
关键帧 frame 存储       卡片自动预览图
```

详情页和缩略图工作室都通过“帧 → 秒”设置 PlayCanvas 动画层，因此同一个片段的默认卡片图与详情页默认位置使用同一帧。

## Error handling

- 非有限、负数或不存在的帧值统一裁剪或回退到 0，不把 `NaN`/`Infinity` 传给动画层。
- 轨道采样时间不足以推断帧率时使用目录条目的帧率；目录缺少有效值时使用 30fps，并由目录内容测试覆盖。
- 单个缩略图生成失败只保留该卡片占位，不影响其他动画的生成和详情页操作。

## Verification

- 帧工具单元测试覆盖 24/30fps、零时长、50% 默认帧、边界裁剪和秒/帧往返换算。
- 动画目录内容测试验证每个条目的帧率与 GLB 实际采样间隔一致。
- 动画预览源码契约测试验证详情页只使用整数帧时间轴、恢复/保存关键帧和缩略图都调用同一默认帧工具。
- 客户端 typecheck/build 通过后，用内置浏览器打开动画库和至少一个 24fps、一个 30fps 动作，确认卡片图来自中间帧、详情页默认当前帧相同、拖动只能按整帧变化且无控制台错误。

## Scope boundary

本次只调整动画目录的预览取帧、时间轴显示和关键帧持久化，不修改动画 GLB、骨骼重定向、动作内容或分镜运行时的动画播放协议。
