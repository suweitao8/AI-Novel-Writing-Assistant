# 空间标记地面物品边缘落点设计

## Background

空间标记识别已经通过 `imageRegion` 把物体的水平经度映射到 3D 场景，但当前固定全景合同要求家具完整位于 `v=0.48` 以上。桌子、椅子、床等 `floor` 标记的框底因此经常位于地平线 `v=0.5` 之上，地面射线无法与 `y=0` 相交，服务端便退回模型返回的径向深度提示。模型的坐标深度不稳定，缺失或接近原点时会落在半球内部，导致物品集中在球体中心而不是地面外圈。

## Decision

### 位置合同

- `imageRegion` 的水平中心继续作为唯一的水平经度来源，不能被模型的 `position.x/z` 覆盖。
- `floor` 标记必须以物体底部接触地面为摆位语义，中心高度固定为 `size[1] / 2`。
- 当框底在地平线下且射线可以向下时，使用射线与地面相交的半径，并裁剪到当前半球可用的最大标记半径。
- 当框底位于地平线或其上方，或射线接近平行地面时，不再使用模型径向深度提示，直接使用当前半球可用的地面外圈半径。这样适配当前家具不跨越 50% 中线的全景 Prompt。
- `wall`、`ceiling` 标记继续使用图像垂直射线和有界径向深度提示；本次不改变它们的深度语义。

### 边界与兼容

- 当前环境的 `maxRadius` 仍由 `domeRadius * 0.45` 提供，作为物品可摆放的外圈边界，避免物体穿出半球网格。
- 旧标记数据继续可读取；重新识别或带 `imageRegion` 的 AI 标记按新合同归一化。
- 手工标记和没有 `imageRegion` 的旧标记保持原坐标，不静默重排用户手工摆位。

## Data flow

`sceneState3dMarkersPrompt` → `imageRegion` → `projectStoryScene3dMarkerPosition` → `normalizeStoryScene3dMarkerSet` → `createSceneMarkerRuntime` → PlayCanvas `setPosition`。

根因修复只落在共享可测试的服务端投影函数，并通过服务层和前端标记运行时合同测试证明：水平经度仍跟随图片区域，floor 半径不再受不可靠模型深度提示影响。

## Verification

- 先新增一个失败回归：floor 框底位于 `v=0.48` 时，缺失/中心化模型坐标仍必须得到 `maxRadius` 外圈位置。
- 再覆盖：向下射线仍按交点计算并裁剪、水平经度不变、wall/ceiling 不回归、手工/无区域标记不变、重复归一化稳定。
- 运行服务端空间标记投影与服务层测试、共享构建、客户端类型检查/构建；最后使用真实页面重新识别并观察至少一个桌椅标记的半径与经度。
