# 模型与动画库搜索设计

## Goal

模型库页面只展示可作为场景前景资产使用的模型，不展示角色模型预览；模型库和动画库都提供即时搜索，帮助用户从较长的资产目录中快速找到目标条目。

## Scope

- 模型库隐藏 `category === "角色"` 的卡片和分类页签。
- 角色模型配置与动画库资源保持不变，分镜和动画预览继续使用既有 UAL2 资源。
- 模型搜索匹配模型名称、文件名和分类。
- 动画搜索匹配动画名称、片段名、动画套装、动作类型和目录标识字段。
- 搜索输入采用 250ms 防抖；清空搜索词后恢复当前分类/筛选条件下的完整列表。
- 搜索或筛选无结果时显示明确空状态，并提供清除搜索/筛选的直接操作。

## Architecture

模型页面在现有目录数据上先建立“可展示模型”视图，再叠加分类和搜索过滤；底层 `MODEL_LIBRARY` 不删除角色条目，避免影响动画、分镜或其他内部资源引用。模型页面的角色分类不参与计数和页签渲染。

动画页面复用现有 `filterAnimationLibraryEntries`，新增可选搜索条件并与组别、套装、动作类型条件取交集。既有分类计数不因搜索词变化，保证搜索无结果时仍可调整筛选；结果数量和空状态反映搜索后的最终结果。

两页都使用项目现有 `Input`、`Search` 图标和语义化主题 token，不新增组件库或依赖。输入框提供可访问名称，清除操作使用可聚焦的按钮，列表卡片和缩略图加载逻辑保持不变。

## Verification

- 先为模型可见性、模型搜索和动画搜索写纯逻辑契约测试，并确认旧实现失败。
- 运行聚焦测试、客户端类型检查和生产构建。
- 使用内置浏览器验证模型页没有“角色”页签/角色卡片，模型搜索可缩小结果；动画搜索可缩小结果，清空后恢复，且无结果状态可见。
