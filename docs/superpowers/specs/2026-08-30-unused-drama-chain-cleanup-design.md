# 漫剧主线无用链路清理设计

## 背景

当前产品以漫剧工作室为主要创作入口。仓库中仍保留两条已经不参与当前产品流程的链路：占星接口只有未实现响应；旧聊天页面已由 Creative Hub 接替，`/chat` 也已重定向到 Creative Hub，但旧页面、旧 SSE 服务和移动端入口仍在代码中保留。

## 决策

本次只清理有完整引用证据、且不会影响漫剧生产主链的失效代码：

1. 删除占星模块的 501 路由，并移除服务端挂载。
2. 删除旧聊天页面、IndexedDB 会话状态、旧聊天 SSE 服务和 `/chat-legacy` 入口。
3. 清理旧入口对应的移动端导航、漫剧聚焦导航过滤、CSS 和测试。
4. 保留 `/chat` 到 `/creative-hub` 的重定向，避免旧书签进入失效页面。
5. 保留历史文档中的迁移记录；更新当前路线文档，避免把旧聊天描述为现行入口。

## 明确保留

- 漫剧 `/drama/studio/:novelId`、历史项目 `/drama/projects/:id` 及 3D 草图深链接。
- 小说作为漫剧内容源的创建、章节和自动导演能力。
- 漫画分格模块、模型/动画资产库、通用 `useSSE`、服务端流式工具、RAG 和 Agent Runtime。

## 兼容与数据边界

本次不删除数据库表、记录或浏览器 IndexedDB 数据，也不执行迁移、重置或清理用户数据。直接访问已经下线的 `/chat-legacy` 将不再提供旧页面；`/chat` 仍然进入 Creative Hub。

## 验证

- 通过客户端和服务端类型检查，确认删除旧引用后构建依赖闭合。
- 运行客户端导航/契约测试和服务端路由测试。
- 用全仓库文本搜索确认旧聊天与占星运行时引用只剩历史文档，确认漫剧主链与共享流式能力仍有引用。
