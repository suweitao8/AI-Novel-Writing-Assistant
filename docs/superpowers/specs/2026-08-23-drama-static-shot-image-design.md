# 漫剧分镜静态画面与成片合成设计

## Background

当前漫剧分镜页面把每个镜头的静态图片称为“首帧”，并保留了“视频提示词”和视频 Provider 任务入口。这个概念来自早期的图生视频方案，但当前产品的实际目标是：每个镜头生成一张横屏静态画面，按镜头时长依次播放，同时叠加旁白、角色对白和字幕，形成最终视频。镜头画面本身不做图生视频，也不做 Ken Burns 推拉等运动效果。

当前底层已经有可复用的静态合成能力：镜头图片保存在 `DramaShot.keyframeData`，配音保存在 `dialogueAudioData`，Remotion 负责按时间轴显示图片和字幕并封装音频。因此本次需要修正产品语义和用户入口，同时避免破坏已有项目数据。

## Decision

采用“产品层改正语义，底层保留兼容”的方案：

1. 用户看到的“首帧”统一改为“分镜画面”或“画面”，包括生成按钮、状态、统计、预览、无障碍文本、提示语和错误文案。
2. 分镜工作台移除“视频提示词”、视频 Provider 选择和创建图生视频任务的用户入口。后端旧接口和历史 `DramaVideoPrompt` 数据暂不删除，作为兼容层保留，但新 UI 不再调用它们。
3. “视频”阶段改为面向用户的“成片”阶段，展示静态分镜画面 + 配音/字幕的合成结果，不展示外部视频通道或图生视频任务状态。
4. 成片渲染固定为静态画面在镜头时长内保持不动。现有本地 FFmpeg 兼容通道中的 `zoompan`/Ken Burns 效果必须移除或绕开，不能改变镜头画面内容。
5. 本阶段不迁移数据库字段、文件名或旧 API 路径：`keyframeData`、`/keyframe` 和历史 `keyframe.*` 文件继续可读写；前端通过“分镜画面”语义封装旧接口，后续如需内部重命名另立迁移设计。

## Data Flow

```text
章节脚本
  -> 分镜镜头（动作 / 台词 / 画面提示词 / 时长）
  -> 每镜生成一张静态分镜画面
  -> 每镜生成旁白或角色对白音频
  -> Remotion 按镜头时长保持图片不动，叠加字幕并封装音频
  -> 横屏成片（MP4 + SRT）
```

图生视频 Provider、视频提示词生成和视频任务轮询不再属于主产品路径。

## Scope

### Frontend

- 更新 `ShotVoiceListPanel`、`DramaStoryboardBoard`、`ShotPreviewDialog`、`DramaVisualPanel` 和 `DramaProjectPage` 的分镜画面命名、状态统计、生成/重生成按钮、预览 `alt` 文本和错误提示。
- 删除分镜卡片与预览弹窗中的“视频提示词”操作及其回调、Provider 任务操作和相关无用导入。
- 将漫剧 Studio 的视频页签和摘要改为“成片”，只呈现静态画面与音频合成入口/结果。
- 保留已有加载、禁用、失败重试和空状态；批量生成按钮继续使用 `AiButton` 和现有设计 token，不新增 UI 依赖。

### Backend and renderer

- 保留 `DramaShotKeyframeService` 的现有数据兼容边界，但更新面向用户的消息和导出/合成警告为“分镜画面”。
- 将成片渲染路径约束为静态图片帧：移除本地 FFmpeg Provider 的 Ken Burns `zoompan`，并保持 16:9、字幕、音频封装和缺失素材降级行为。
- 不删除旧视频提示词路由、Provider 适配器或数据库表；它们不再由新前端调用，避免历史项目和并行工作流受到破坏。

### Documentation and contracts

- 更新受影响的模块注释和长期 Wiki，明确“分镜画面”和“成片合成”的边界。
- 增加回归断言：产品 UI 不再出现首帧/视频提示词入口；渲染命令不再包含 `zoompan`/Ken Burns；旧 `keyframeData` 读取仍可工作。

## Failure Handling

- 分镜画面生成中：显示“画面生成中”，禁止重复提交并继续轮询。
- 分镜画面生成失败：显示错误和“重试生成画面”，不创建视频任务作为兜底。
- 成片缺少画面：继续使用已有占位画面并记录 warning；不能隐式触发图生视频。
- 成片缺少配音：继续按现有规则静音合成并明确提示缺少配音。
- 历史数据仍只有 `keyframeData`：正常读取并显示为“分镜画面”，不要求用户迁移数据库。

## Verification

- 前端聚焦测试/类型检查：覆盖分镜列表、完整分镜工作台、预览弹窗和成片页的文案与回调边界。
- 服务端/渲染测试：检查静态图片保持、字幕时间轴、音频封装、缺失素材 warning，以及 FFmpeg 参数不再含 `zoompan`。
- 运行 `git diff --check`、客户端 typecheck 和受影响的服务/渲染测试；UI 浏览器验收按项目规则交由用户完成。

## Out of Scope

- 不做数据库字段从 `keyframeData` 到 `shotImageData` 的迁移。
- 不删除历史视频提示词数据或后端兼容接口。
- 不引入新的视频运动模板、镜头动画或图生视频 Provider。
