# 分镜卡片四行紧凑布局设计

## 背景

分镜列表的右侧信息区目前把分镜设计、运镜、场景、出场角色、英文画面提示词、旁白/对白和配音拆成了多个视觉区块。画面提示词是给图片生成链路使用的内部数据，紧凑列表并不适合直接展示；运镜也不属于当前静态分镜的展示内容。多个区块叠加后，单张分镜卡片高度过大，用户一次能看到的分镜数量变少。

## 目标

- 保留分镜图、分镜序号和景别信息。
- 将右侧信息收敛为最多四个内容行：分镜设计、场景/角色、旁白/对白、配音。
- 紧凑卡片不展示运镜，也不展示英文画面提示词或提示词展开区。
- 配音仍沿用实际音频状态：没有可播放音频时只显示生成按钮；有可播放音频时显示真实进度和重新生成按钮。
- 保留现有数据字段和生成链路，不改变服务端分镜结构或图片生成所需的 `visualPrompt`。

## 方案选择

1. 只删除画面提示词：改动最小，但运镜和多个区块仍会造成卡片过高。
2. 采用四行紧凑信息布局：将设计内容与标签同行，将场景和角色合并一行，将旁白/对白和配音各占一行。它同时解决信息密度和中文可读性问题，选为本方案。
3. 把英文画面提示词翻译后继续展示：仍会占用高度，而且会把生成内部字段暴露给不需要它的用户，不采用。

## 展示结构

右侧区域保留镜头头部“第 N 镜 · 景别”，其下按顺序展示：

1. `分镜设计` 标签与 `action` 内容同行；内容最多显示两行。
2. `场景/角色` 标签与场景名、角色状态徽标同行；内容允许自然换行。
3. `旁白/对白` 标签与解析后的旁白或对白内容同行；没有解析段时使用镜头原始 `dialogue`，内容最多显示两行。
4. `配音` 标签与真实音频播放器同行；没有音频时只保留生成配音按钮，不渲染未生成状态或伪进度条。

`shotSize` 仍保留在镜头头部；`cameraMove` 和 `visualPrompt` 只保留在数据与生成链路，不进入紧凑卡片。

## 状态与交互

- 生成配音和重新生成继续使用 `AiButton`，保留禁用、加载文案和已有错误反馈。
- 音频播放器继续使用真实 `duration` 与可拖动进度，不新增估算时长。
- 空内容不创建多余空行；没有旁白/对白时隐藏该行，没有场景和角色时隐藏场景/角色行。
- 分镜图、3D 图切换、编辑 3D、生成 AI 图等现有操作不变。
- 使用现有语义颜色、间距和焦点样式，不引入新的颜色或组件。

## 验证

- 更新分镜摘要契约测试，确认紧凑组件仍显示设计、场景/角色、旁白/对白和配音入口。
- 测试明确确认紧凑卡片源码不再渲染运镜、画面提示词和 `<details>` 展开区。
- 运行分镜相关前端测试和客户端 TypeScript 检查。
- 通过运行中的分镜列表确认无音频和已有音频两种状态均保持可用。
