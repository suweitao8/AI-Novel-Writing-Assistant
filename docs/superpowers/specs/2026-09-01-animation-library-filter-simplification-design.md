# 动画库筛选收敛设计

## Background

动画库入口目前同时展示“用途”“来源”“细分类”和“套装/动作/姿态/武器”四套筛选。它们都能工作，但首屏需要用户同时理解多个分类体系，横向按钮和下拉框也挤压了动画卡片区域。

## Decision

入口页只保留三类用户可见控制：

1. **用途**：保留“分镜可用 / 兼容动画 / 全部”，它回答的是当前结果能否用于分镜，不与动作分类混淆。
2. **分类**：使用现有 `ANIMATION_LIBRARY_GROUPS` 作为唯一大类入口，改成一个原生下拉框，选项为日常动作、日常互动、生活与表演、徒手战斗、武器战斗、旧动画，并附带当前结果数量。
3. **搜索**：保留名称、片段名和已有标签搜索，支持点击提交和回车提交。

入口页移除细分类横向按钮以及套装、动作、姿态、武器四个下拉框。动画条目的这些字段继续保留在数据模型和 `filterAnimationLibraryEntries` 中，卡片副标题继续展示套装、分类和姿态，避免丢失信息或影响分镜侧已有筛选能力。

## Interaction

- 用途切换会清空大类选择并回到第 1 页。
- 分类下拉选择会按用途、分类和搜索条件交集刷新卡片，并回到第 1 页。
- 搜索只在提交后生效；输入框保留当前输入，点击“清除筛选”时同时清空输入和已提交搜索。
- 当当前用途下分类没有结果时，分类选择自动回到“全部”。
- 原生 `SelectControl` 继续提供键盘上下选择、Enter 确认和 Tab 聚焦；搜索表单保留可访问 label。

## Scope and compatibility

只调整 `AnimationLibraryPage` 的入口展示和本地状态。配置层的分类、动作、姿态、武器字段不删除，过滤函数签名不变，动画详情页和分镜动画选择器不改动。

## Verification

- 更新入口页结构测试，断言页面只暴露用途、单一分类下拉和搜索，并断言旧的细分类/四个详情筛选入口不再挂载。
- 运行动画相关聚焦测试、客户端类型检查。
- 使用内置浏览器检查桌面和窄屏布局，确认首屏筛选区域变为单行/可换行的简洁布局，分类和搜索仍可操作，控制台无错误。
