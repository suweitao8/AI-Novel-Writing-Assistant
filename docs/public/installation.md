# 安装与准备

这篇文档帮助你从源码启动 AI 小说创作工作台（网页版），并确认模型、存储和知识库能力是否可用。

## 启动方式

本项目以纯网页形式运行，从源码启动：

1. 安装 Node.js 与 pnpm。
2. 克隆仓库并安装依赖：`pnpm install`。
3. 启动开发环境：`pnpm dev`。
4. 打开浏览器访问客户端地址（默认 http://localhost:5174），进入系统设置。
5. 配置至少一个可用的文本模型。
6. 创建一本测试小说，跑通新手上路。

## 首次启动前准备

你需要准备：

- 一个可用的 LLM API Key。
- 供应商的 Base URL 或官方兼容接口。
- 一个适合规划、分析和正文生成的模型。
- 稳定网络连接。
- 足够的本地磁盘空间，用于保存数据库、日志、素材和生成结果。

如果你还没有确定模型，推荐先用一个响应快、成本低的文本模型跑通主链，配置入口在系统设置的模型设置里。

## 基础配置顺序

推荐按这个顺序完成：

1. 打开系统设置。
2. 在模型设置里配置文本模型（支持 API Key 或本机订阅通道）。
3. 使用连接测试确认模型可以返回结果。
4. 创建一本测试小说。
5. 输入一句简单灵感，例如“一个新人作者在灵感市场里寻找失落故事”。
6. 跟随新手上路或自动导演推进到第一章。

先跑通最短路径，再配置知识库、写法引擎和高级模型路由，会更容易定位问题。

## 数据保存位置

源码运行时，小说数据库、任务状态、配置和生成产物保存在仓库 server 目录的本地数据库文件中。你可以在故障排查文档中查看日志和数据备份建议。

重要项目建议定期备份。备份时优先保留：

- 应用数据库文件。
- 小说导出文件。
- 角色、世界、知识库和写法资产。
- 任务日志或错误截图。

不要在没有备份的情况下删除数据库文件或重置数据。

## Qdrant 是否必须

Qdrant 用于向量检索和知识库召回。它不是创建小说和生成第一章的硬性前置条件，但会影响资料检索、拆书沉淀和长篇一致性。

推荐策略：

- 只想先体验主链：先不配置 Qdrant。
- 需要知识库检索：配置 Qdrant 并测试索引。
- 需要大量参考资料：优先保证 Qdrant 稳定运行。

如果知识库不命中，先检查文档是否完成索引，再检查检索设置和 Qdrant 连接。

## 构建与站点预览

构建生产产物：

```bash
pnpm build
```

只预览公开站点：

```bash
pnpm --filter @ai-novel/site dev
```

## 启动后建议

启动完成后，先做三件事：

1. 在系统设置里完成模型连接测试。
2. 用一条简单灵感创建测试小说。
3. 在任务中心确认长任务能正常显示进度和结果。

这三步能覆盖模型、数据库和任务状态。如果任一步失败，先阅读《常见问题》和《故障排查》。
