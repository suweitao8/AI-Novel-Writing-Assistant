# 设置页创作可用性原则

## Background

系统设置页承载模型厂商、模型路由、知识库、写法引擎、自动导演授权和桌面维护等能力。对于完整写作新手来说，这些配置如果按技术模块平铺，会让用户误以为必须理解所有参数后才能开始写小说。

设置页的首要任务不是展示所有参数，而是回答用户最关心的问题：现在能不能开始创作，如果不能，还差哪一步。

## Decision

完整小说模式下，设置页以“创作可用性检查”作为首屏核心信息。页面应先展示开始创作所需的模型和路由状态，再展示知识库、写法引擎、自动导演高级设置和系统维护。

漫剧专注模式是另一条明确的产品工作流：设置总览不展示小说链路的“创作可用性检查”，也不为这张检查卡触发知识库和写法引擎状态查询；总览直接提供漫剧需要的模型、旁白音色、画风、记录和视频输出入口。被收起的小说设置路由与组件仍保留，关闭专注模式即可恢复，不能通过删除实现“隐藏”。

知识库、写法引擎和通知通道属于增强或高级能力，不能在视觉和文案上阻塞用户开始创作。模型厂商详情默认降噪，只展示可用状态、当前模型、余额摘要和主操作；技术参数进入高级详情。

## Current Rule

- 完整小说模式的首屏必须清楚说明基础创作链路是否可用。
- 漫剧专注模式的设置总览首屏只呈现漫剧当前需要的配置，不显示小说可用性检查，也不请求仅用于该检查的 RAG / 写法状态。
- 缺少正文模型时，引导用户先配置模型厂商。
- 模型路由异常时，引导用户进入模型路由管理。
- 知识库未启用时，明确说明这是可选增强，不阻塞创作。
- 写法引擎用“快速检测 / 稳定推荐 / 长文提取”这类用户任务语言表达，分钟数保留在高级设置。
- 审批授权、导演跟进通道、桌面维护不应占据开始创作前的主要注意力。
- 漫剧专注模式仍保留模型、旁白音色、画风、记录和视频输出；隐藏只作用于导航与小说 readiness 投影，不删除数据、路由或组件。

## Failure Modes

- 如果设置页再次变成厂商、API 地址、模型标签和运行参数的长列表，新手会难以判断下一步，容易放弃开书。
- 如果知识库或写法引擎文案暗示“必须先配置”，用户会把增强能力误解为创作前置条件。
- 如果模型路由异常只显示在模型路由页，设置页无法承担全局创作入口的诊断职责。
- 如果漫剧专注模式仍加载小说 readiness 查询，设置页会在不展示结果的情况下访问无关能力，增加启动噪声并让工作流边界失真。
